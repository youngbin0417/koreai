# 공공 동물병원 인허가 조회

확인: **2026-10-19**. 행동 `animal-hospitals.search`, 연결 방식 `public-data`(공공파일 조회). **공급자 키·서비스 계정 없이** 지역별 공식 CSV를 받아 병원명·주소·인허가 상태를 조회합니다. HTTP/MCP에서 KoreAI 클라이언트 인증과 행동 권한은 필요합니다.

## 화면에서 사용

1. **확장 계획 → 공공 동물병원 정보 → 조회 기능 열기**를 선택합니다.
2. **예시 입력 불러오기**로 형식을 확인하고 지역을 선택합니다. 지역 이름은 입력 형식의 공식 목록 245개 중 하나를 정확하게 사용합니다. 예: `서울강남구`, `서울종로구`, `제주제주시`.
3. 필요하면 병원명과 상태·페이지를 지정하고 실행합니다. 요청 구조 미리보기는 외부 호출 없이 동작합니다.

```json
{"region":"서울강남구","query":"동물","status":"normal","page":1,"limit":10}
```

| 입력 | 의미 |
|---|---|
| `region` | 필수. 공식 시·군·구/본청 단위 이름. `서울` 같은 광역 검색이나 임의 코드는 받지 않음 |
| `query` | 선택. 해당 지역 파일에서 병원명의 부분 일치, 최대 100자 |
| `status` | `normal`(기본, 인허가 코드 `01`) 또는 `all`(폐업·휴업 등 포함) |
| `page` / `limit` | 파일 안 검색 결과의 페이지, 기본 1/10. 페이지 1~1,000, 페이지당 최대 50개 |

지역 코드는 [공식 다운로드 화면](https://file.localdata.go.kr/file/animal_hospitals/info)의 목록을 참조합니다. 화면의 최신 지역 목록과 차이가 생기면 코드표를 갱신해야 합니다. 병원명·상태·페이지는 파일을 받은 뒤 로컬에서 적용하므로 공급자에게 병원 검색어를 보내지 않습니다.

## 결과 해석

- 관리번호·제공 자치단체 코드·병원명·도로명/지번 주소·제공된 전화번호를 반환합니다. 관리번호는 문자열로 보존합니다.
- `registration`은 인허가 상태입니다. **`currentlyTreating`·`emergencyAvailable`은 미확인으로 `null`**입니다. 정상 등록을 현재 진료·야간 응급·예약 가능으로 해석하지 않습니다.
- `dataUpdatedAtRaw`·`lastModifiedAtRaw`는 행별 공급자 시점 원문입니다. `retrievedAt`과 구분합니다. 파일 전체의 자료 기준 시각은 확인되지 않아 `providerUpdatedAt: null`입니다.
- 원좌표는 `coordinates.crs: "EPSG:5174"`의 X/Y입니다. WGS84 위·경도로 계산하지 않으며 `latitude`·`longitude`는 `null`입니다. 좌표가 빠져 있어도 주소 기반 병원 정보는 반환합니다.
- `totalSourceRows`는 해당 지역 파일의 행 수, `totalMatches`는 필터 결과 수입니다. 전국 병원 수를 뜻하지 않습니다. `no_match`와 `empty_page`를 구분합니다.
- `snapshotSha256`으로 읽은 파일을 구분합니다. 매 요청마다 다운로드하므로 서로 다른 페이지의 지문이 다르면 원본이 갱신됐을 수 있습니다. 파일을 로컬에 영구 보관하거나 자동으로 모든 지역/페이지를 조회하지 않습니다. 작업 결과와 이력은 기존 엔진 정책대로 저장합니다.

## 공식 근거와 파일 처리

[공공데이터포털](https://www.data.go.kr/data/15045050/fileData.do)은 지역별 인허가 자료·EPSG:5174·일일 갱신과 약 2일 전 기준, 이용허락범위 제한 없음을 안내합니다. 포털 메타데이터 수정일과 실제 파일의 행별 갱신일은 서로 다른 값입니다.

공식 다운로드 화면의 JavaScript와 동일하게 **다운로드 한도 확인 → 지역 CSV 다운로드** 순으로 호출합니다. 고정 HTTPS 도메인·경로와 공식 Referer만 사용하고 리디렉션·HTML 응답을 거절합니다. 한도/네트워크 실패를 빈 정상 결과로 바꾸거나 반복 재시도하지 않습니다.

실제 파일은 응답 헤더가 UTF-8이어도 CP949일 수 있음을 확인했습니다. UTF-8을 엄격히 검사하고, CP949는 디코딩·재인코딩 일치까지 검사합니다. 따옴표·쉼표·줄바꿈·BOM을 처리하고 손상된 CSV·잘못된 지역·중복 관리번호·일자·좌표를 거절합니다. 제한은 파일 5MB·행 20,000개·필드 10,000자·전체 요청 30초이며 취소를 지원합니다.

## 검증과 후속

강남구 실제 공식 파일을 **KoreAI HTTP 요청부터 다운로드·정규화·결과 조회까지** 확인했습니다. 사용자 계정이나 키는 사용하지 않았습니다. 모의 테스트와 실제 공개 파일 확인은 별도로 기록하며 시험 결과를 운영 DB의 지원 실적으로 옮기지 않았습니다. [검증 기록](VALIDATION.md#2026-10-19-동물병원-공공파일-조회-검증)

후속: 다른 지역·빈 파일·지역 코드 변경·공급자 한도 검증, 필요 시 공식 근거를 갖춘 지도 좌표 변환. 마이펫플러스 예약·상담, 진료비 지역 통계, 현재 진료·응급 여부는 별도 제공 경로와 행동으로 정의합니다.
