# E-Gen 병·의원 찾기

문서 확인·구현일: **2026-10-14**. 행동 ID는 `egen.hospitals.search`, 계정 종류는 `egen-api`입니다. [국립중앙의료원 전국 병·의원 찾기 서비스](https://www.data.go.kr/data/15000736/openapi.do)의 XML 목록 조회를 사용합니다.

## 연결과 검색

1. 공공데이터포털에서 **국립중앙의료원_전국 병·의원 찾기 서비스**를 활용 신청합니다.
2. **연결 계정 → 계정 연결 → E-Gen 병·의원 찾기**에서 일반 인증키(Decoding)를 등록하고 검색 행동을 허용합니다.
3. **확장 계획 → E-Gen 병·의원 정보 → 조회 기능 열기**에서 예시 입력을 불러옵니다.
4. 지역·기관명·진료요일을 확인한 뒤 **실행 요청**을 누릅니다. 미리보기는 키 조회·외부 호출 없이 동작합니다.

```json
{"region":"서울특별시","district":"강남구","name":"의원","day":8,"page":1,"limit":10}
```

`region`은 필수 시도명입니다. `district`(시군구)·`name`(기관명)·`day`는 선택 조건입니다. 진료요일 코드는 **월~일 1~7, 공휴일 8**입니다. 요일 검색은 제공된 일정 조건이며 현재 진료 가능 여부를 확인하는 기능이 아닙니다.

`page`는 기본 1·최대 1,000, `limit`은 기본 10·최대 100입니다. 예시는 형식 검토용이며 특정 기관·지역의 자료 존재를 보증하지 않습니다. 계정 연결 후 **AI 대화**의 새 대화에서 이 행동을 선택할 수도 있습니다. HTTP·MCP는 기존 행동 실행 인터페이스를 사용합니다.

## 결과

| 필드 | 의미 |
|---|---|
| `hospitals[].id`, `name` | 기관 식별자와 이름 |
| `address`, `phone` | 제공된 주소·대표전화; 미제공이면 `null` |
| `institutionType` | 공급자의 기관분류 코드·명칭; 미제공 명칭을 추정하지 않음 |
| `latitude`, `longitude` | 제공된 WGS84 위도·경도 |
| `hours[]` | 월요일~공휴일의 `day`, `label`, `start`, `end` |
| `start/end.value` | 유효한 제공 시각을 `HH:MM`으로 표시 |
| `start/end.raw` | 공급자의 원래 시각 문자열 |
| `start/end.status` | `provided`, `unavailable`, `invalid` |
| `currentCareAvailability` | `not_verified`; 현재 진료 가능 여부 미확인 |
| `retrievedAt`, `providerUpdatedAt` | 조회 시각과 미제공 자료 갱신 시각(`null`) |
| `pagination`, `source` | 페이지·전체 수·다음 페이지, 국립중앙의료원 출처 |

공식 활용가이드의 3/4자리 시간 표기를 처리합니다. `830`은 `08:30`, `0000`은 `00:00`, `2400`은 `24:00`으로 표시하고 원문을 보존합니다. 시간 누락을 휴진으로 판단하지 않으며, 잘못된 시간은 값 없이 `invalid`로 남깁니다. 방문 전 기관에 전화로 실제 진료 가능 여부를 확인하세요.

빈 결과·빈 페이지는 `status: no_data`입니다. 인증 오류는 작업을 `awaiting_auth`로 보존하며 해당 키·활용신청 권한을 확인한 뒤 재개합니다. 한도·IP 접근 거절·통신 실패·취소를 구분하고 잘못된 XML·페이지 불일치는 `INVALID_RESPONSE`로 중단합니다.

## 검증과 다음 단계

실행기는 `fast-xml-parser` 5.11.2로 XML 문법을 검증하고 문자열·엔티티·CDATA를 처리합니다. 외부/사용자 엔티티 선언과 DTD는 받지 않습니다. 전화번호·기관 식별자의 앞자리 0을 보존하고 선언한 결과 필드만 반환합니다.

API 검증과 모바일 화면의 키 등록 → 검색 조건 → 미리보기 → 결과 확인을 모의 응답으로 검사했습니다. [검증 기록](VALIDATION.md#2026-10-14-e-gen-병의원-검색-검증)

실제 키·지역별 병원 정보·갱신 조건 검증은 남아 있습니다. 실제 지원 수는 모의 테스트로 증가시키지 않습니다. 진료과목/기관분류 코드 필터, 기관 상세정보는 후속 작업이며 실시간 응급실 병상·예약·진료 가능 판정은 현재 행동의 범위에 포함되지 않습니다. [할 일 목록](../TODO.md)
