# KOSIS 지역 인구·고령화 지표 조회

확인일: **2026-10-20**. `kosis.aging.search`·전용 계정·요청 미리보기를 구현했습니다. **본인 인증키의 정상 응답 검증은 대기**이며 모의 성공과 무효 키 오류는 지원 실적에 포함하지 않습니다.

## 연결과 실행

1. [KOSIS 공유서비스](https://kosis.kr/openapi/index/index.jsp)에서 로그인·활용신청 후 본인 인증키를 발급받습니다. 공공데이터포털 키나 문서의 예제 키를 사용하지 않습니다.
2. KoreAI **연결 계정 → 계정 연결 → KOSIS 지역통계**에서 `apiKey`를 등록하고 **KOSIS 지역 인구·고령화 지표 조회**를 허용합니다.
3. **확장 계획 → KOSIS 지역통계 → 조회 기능 열기**에서 예시를 불러오고 시점·지역·항목을 확인한 뒤 실행합니다. 예시는 서울·경기, 서울 시간 기준 전월입니다. 전월 자료가 아직 발표되지 않았다면 이전 시점을 지정합니다.

```json
{
  "regionCodes": ["11", "31"],
  "itemIds": ["T10", "T001", "T002"],
  "frequency": "M",
  "from": "202608",
  "to": "202609"
}
```

에이전트에서도 같은 행동을 발견하고 실행할 수 있습니다. 별도 행동·계정 권한을 부여하며 조회 결과는 `external_data`로 전달합니다. 미리보기에는 키가 없고 외부 호출도 없습니다. 서버의 키·SQLite는 로컬에 보관됩니다. Linux에서는 기존 암호화 저장소를 사용합니다.

## 첫 통계표와 입력

공식 [고령인구비율(시도/시/군/구) 표](https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1YL20631&conn_path=I2)의 기관 **101**, 표 **DT_1YL20631**, 분류 **SGG(행정구역별)**를 사용합니다. 제공 경로의 기관과 자료 작성기관(행정안전부 주민과)을 구분합니다. 공식 화면의 표 설정·항목·지역 코드·월/연 수록기간을 확인했습니다. 일반 API의 제한된 선택 조회이며 대용량 API·전체 표 수집은 후속 범위입니다.

| 입력 | 범위 |
|---|---|
| `regionCodes` | 아래 검토된 전국·시도 코드 중 1~5개, 중복 불가 |
| `itemIds` | `T10` 고령인구비율(%), `T001` 65세이상인구(명), `T002` 전체인구(명). 기본 세 항목, 중복 불가 |
| `frequency` | `M` 월 / `Y` 연 |
| `from`·`to` | 월 `YYYYMM`(200801 이후), 연 `YYYY`(2000 이후). 양 끝 포함 최대 12개 시점 |

월 자료와 연 자료의 기준을 혼용하지 않습니다. 입력 가능한 시점과 해당 지역에 실제 자료가 있는 시점은 다릅니다. **200801·2000은 확인 당시 표 전체의 수록 시작**이며, 모든 지역이 그때부터 존재한다는 의미가 아닙니다. 원문 주석과 행정구역 개편을 확인하세요.

## 요청과 결과 의미

[현재 통계자료 문서](https://kosis.kr/openapi/devGuide/devGuide_0201List.do)의 HTTPS `Param/statisticsParameterData.do?method=getList`를 사용합니다. `orgId`·`tblId` 고정, `objL1`·`itmId`는 선택 코드의 `+` 구분 문자열, `prdSe`·`startPrdDe`·`endPrdDe`·`format=json`·`jsonVD=Y`·**`smblChk=Y`**를 전달합니다. `URLSearchParams`로 값과 키를 한 번 인코딩합니다. 다중 선택의 실제 서버 반환은 본인 키 검증에 남겨 둡니다.

- `observations`: 요청한 표·기관·지역·항목·주기·시점·단위를 대조한 셀입니다. 중복 셀·추가 분류가 섞이면 중단합니다. 연 주기 응답은 `A` 또는 `Y`를 `Y`로 정규화하고 `frequencyRaw`도 보존합니다. 이 표의 실제 연 응답 코드는 본인 키로 확인해야 합니다.
- `valueRaw`: `DT` 원문. `numericValue`도 **문자열**로 반환해 큰 정수·소수 정밀도를 보존합니다. 순수 숫자가 아니면 `null`입니다. 통계부호·쉼표·문자열을 제거해 숫자로 추정하지 않습니다.
- `valueKind`: `numeric` / `symbol_or_text` / `missing`. 부호의 의미·잠정/확정 여부를 추정하지 않으며 `provisional`은 `null`입니다. 원문 주석을 확인합니다.
- `coverage.notReturned`: 요청한 지역×항목×시점 중 응답에 없는 조합입니다. 반환된 빈 셀·숫자 0과 구분하며 미발표·폐지·데이터 부재의 원인을 단정하지 않습니다.
- `period`: 통계 기준 시점, `providerModifiedOn`: 행의 최종 수정일, `retrievedAt`: KoreAI 조회 시각. 서로 대체하지 않습니다.
- `currentPopulation`: `null`. 주민등록인구 기반 지표는 인구총조사·실시간 인구·개인 자격과 다릅니다.
- `source`: 출처·표 링크·문서. 결과를 재표시할 때 **출처·통계표·시점·단위**를 함께 제공합니다.

숫자 셀을 연산할 때는 단위와 부호·기준 시점을 먼저 확인합니다. 광역 합계와 전국을 합산하거나 개편 전후 지역을 그대로 이어 비교하지 않습니다.

## 오류·호출 제한

실제 무효 시험 키로 **HTTP 200 / `err=11`**을 확인했습니다. `10`·`11`·HTTP 401/403은 `awaiting_auth`로 보존하며 키를 수정한 뒤 같은 작업을 재개할 수 있습니다. 공급자 오류 메시지·키가 든 URL은 반환하지 않습니다.

`30`은 빈 결과, `40`·HTTP 429는 호출 한도, `31`·`41`은 행 한도, `42`는 이용 제한, 다른 오류는 실패로 구분합니다. 자동 재시도·추가 페이지·자료 수집은 하지 않습니다. 단일 요청 최대 180셀·2MB·30초와 취소·UTF-8 검사를 적용합니다. HTTP 200의 HTML이나 모양이 바뀐 JSON은 성공으로 처리하지 않습니다.

[2026-02-05 공지](https://kosis.kr/openapi/community/community_01Detail.do?p_id=49)는 2026-03-05부터 HTTPS 전용·분당 1천건을 안내했으나, **[2026-07-09 후속 공지](https://kosis.kr/openapi/community/community_01Detail.do?p_id=51)의 2026-07-15 시행 분당 200건 제한**을 현재 기준으로 사용합니다. 같은 키의 다른 클라이언트 사용량도 고려해 호출 빈도를 조절하세요. [활용약관](https://kosis.kr/openapi/introduce/introduce_02List.do)의 출처 표시·키 관리·이용 범위를 확인합니다.
