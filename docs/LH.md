# LH 임대·분양 공고 조회

확인일: **2026-10-20**. [공공데이터포털 분양임대공고문 조회 서비스](https://www.data.go.kr/data/15058530/openapi.do)와 첨부 **20260708 활용가이드**를 기준으로 첫 목록 조회를 구현했습니다. 본인 승인 키의 정상 응답 검증 전이며 실제 지원 실적으로 집계하지 않습니다.

## 계정 연결과 실행

1. 공공데이터포털에서 **한국토지주택공사_분양임대공고문 조회 서비스**를 활용 신청하고 본인 일반 인증키(Decoding)를 준비합니다.
2. KoreAI **연결 계정 → 계정 연결 → LH 분양임대공고**에서 `serviceKey`를 등록하고 **LH 임대·분양 공고 조회**를 허용합니다.
3. **확장 계획 → LH 청약플러스 → 조회 기능 열기**에서 예시를 불러오고 요청 구조를 확인한 뒤 실행합니다.

행동 ID: **`lh.notices.search`** · 계정 종류: **`lh-api`**

HTTP/MCP에서도 같은 행동·계정 권한을 적용합니다. 키는 Linux 암호화 저장소에 보관하고 HTTPS 요청에만 주입합니다. 키·공급자 원문 오류·키 포함 URL을 에이전트나 일반 오류로 전달하지 않습니다. API 조회에는 브라우저나 그래픽 환경이 필요하지 않습니다.

포털은 개발/운영 자동승인·무료·개발계정 트래픽 10,000을 안내합니다. 실제 승인·사용량 조건은 본인 계정에서 확인하세요. 조회 권한을 개인 청약 계정·자격·신청 권한으로 확대하지 않습니다.

## 입력

```json
{
  "postedFrom":"2026-09-20",
  "postedTo":"2026-10-20",
  "noticeType":"06",
  "regionCode":"36110",
  "page":1,
  "limit":10
}
```

| 입력 | 의미 |
|---|---|
| `postedFrom`, `postedTo` | 필수 게시일 검색 범위, 실제 달력의 `YYYY-MM-DD`. 종료일은 시작일 이후 또는 같은 날 |
| `closingFrom`, `closingTo` | 선택 공고 마감일 검색 범위. 둘 다 지정하면 오름차순 |
| `name` | 선택 공고명, 1~50자 |
| `noticeType` | 선택 LH 상위 유형 코드, 아래 6개 |
| `regionCode` | 선택 LH 가이드 지역 코드. 서울 `11`, 경기 `41`, 세종 **`36110`** 등 |
| `status` | 선택 `공고중`·`접수중`·`접수마감`·`상담요청`·`정정공고중` |
| `page`, `limit` | 각각 1~1,000·1~100, 기본 1·10. KoreAI의 제한이며 공급자 최대치로 주장하지 않음 |

유형: `01` 토지, `05` 분양주택, `06` 임대주택, `13` 주거복지, `22` 상가, `39` 신혼희망타운.

지역은 **가이드의 LH 코드 표**를 사용합니다. 다른 서비스의 지역 코드와 혼용하지 않습니다.

| 코드 | 지역 | 코드 | 지역 |
|---|---|---|---|
| `11` | 서울특별시 | `12` | 전남광주통합특별시 |
| `26` | 부산광역시 | `27` | 대구광역시 |
| `28` | 인천광역시 | `30` | 대전광역시 |
| `31` | 울산광역시 | `36110` | 세종특별자치시 |
| `41` | 경기도 | `43` | 충청북도 |
| `44` | 충청남도 | `47` | 경상북도 |
| `48` | 경상남도 | `50` | 제주특별자치도 |
| `51` | 강원특별자치도 | `52` | 전북특별자치도 |

확인일의 공식 표를 그대로 보존한 목록입니다. 실제 필터 적용·변경된 지역 제공 범위는 본인 키로 확인해야 합니다. 응답은 지역 이름만 제공하므로 입력 코드와 동일하다고 역추정하지 않고 `regionNameRaw`로 보존합니다. 전국 공고도 자동 제외하지 않습니다.

화면 예시는 **Asia/Seoul 오늘과 30일 전**의 게시일 범위·임대주택을 요청 시 계산합니다. 저장한 작업 날짜는 자동 변경하지 않습니다. 특정 기간의 자료 존재나 ‘접수중’인 개인의 신청 가능 여부를 보장하지 않습니다.

## 포털 요약과 첨부 가이드의 차이

현재 포털 요약은 요청에 `PAN_NT_ST_DT`·`CLSG_DT`와 점 구분 날짜를 표시합니다. **20260708 첨부 가이드**는 게시일 범위 `PAN_ST_DT`·`PAN_ED_DT`, 선택 마감일 범위 `CLSG_ST_DT`·`CLSG_ED_DT`를 명시하고 `YYYYMMDD`로 설명합니다. 첫 구현은 명시적인 범위가 있는 첨부 가이드를 따릅니다. 인증키 이름도 첨부의 소문자 `serviceKey`를 사용합니다.

```text
GET https://apis.data.go.kr/B552555/lhLeaseNoticeInfo1/lhLeaseNoticeInfo1
  ?PAN_ST_DT=20260920&PAN_ED_DT=20261020&UPP_AIS_TP_CD=06
  &PG_SZ=10&PAGE=1&serviceKey={암호화 저장한 키}
```

HTTP 주소·SSL 미지원으로 표시한 구 안내 대신 포털의 HTTPS 주소와 실제 HTTPS 인증 오류 확인을 근거로 HTTPS만 사용합니다. HTTP 대체·리다이렉트 재전송은 하지 않습니다. 날짜 인자의 실제 적용·경계 조건과 필터 조합은 본인 승인 키로 검증해야 합니다. 서로 다른 인자를 동시에 전송하거나 오류 시 다른 규격으로 자동 재시도하지 않습니다.

## 결과와 식별자

- `reference`는 `noticeId`(PAN_ID)·상위 유형·세부 유형·공급정보 구분·고객센터 시스템 코드입니다. 앞자리 0을 보존합니다. `noticeKey`는 이 식별자들을 결합하며 이름이나 PAN_ID 하나만으로 공고를 합치지 않습니다.
- `title`·유형명·세부 유형명·`regionNameRaw`·`statusRaw`는 공급자 원문입니다. 새로운 상태도 선택 조건이 없으면 원문으로 반환합니다.
- `publishedOn`/`publishedOnRaw`: 게시일, `announcementOn`/원문: 모집공고일, `closingOn`/원문: 공고 마감일입니다. 세 날짜와 청약 접수 일정을 구분합니다. 토지/상가는 모집공고일이 없을 수 있습니다.
- 날짜 형식의 값은 달력을 검증하고 ISO 날짜로 반환합니다. `상시` 등 비날짜 안내는 원문만 보존하고 날짜는 `null`입니다. 정정공고에서 날짜가 바뀌는 등 검색 결과가 요청 범위와 어떻게 연결되는지는 별도 실계정 검증 항목입니다.
- `currentlyAcceptingApplications`·`userEligible`·`applicationSubmitted`는 **`null`**입니다. 현재 개인 접수 가능·자격·기존 신청 내역을 조회하거나 판정하지 않습니다. 신청·서류 제출·계약도 실행하지 않습니다.
- `providerOutputAtRaw`는 공급자 `RS_DTTM` 출력 시각 원문입니다. 자료 갱신 시각으로 바꾸거나 시간대를 추정하지 않습니다. `retrievedAt`은 조회 시각, `providerUpdatedAt`은 `null`입니다.

결과의 `source.attribution`에 한국토지주택공사 출처를 포함합니다. 원문 공고와 정정 내용을 확인하고 재표시에도 조회 범위·출처를 함께 표시하세요.

## 상세 링크와 페이지 검증

`detailLinks.desktop`·`mobile`은 URL과 `check`를 반환합니다. 확인된 HTTPS `apply.lh.or.kr`의 현재 상세 경로와 문서의 구 `/LH/index.html` 경로만 처리합니다. URL의 공고 ID·고객 시스템이 존재하고 응답과 일치해야 URL을 제공하며 추가 유형 인자도 있으면 대조합니다.

`matched_reference`는 **링크 인자 대조**를 통과했다는 뜻입니다. 실제 페이지 접속·로그인·원문 최신성·예약/신청 가능을 확인한 상태가 아닙니다. `mismatched_reference`, `unverified_reference`, `rejected_url`, `missing`이면 URL은 `null`입니다. 외부 도메인·HTTP·자격정보·중복 인자·다른 경로는 거절하며 링크를 재구성하거나 따라가지 않습니다. 첨부파일도 다운로드하지 않습니다.

첨부 예제의 첫 행은 PAN_ID와 새 상세 링크의 panId가 달라 두 링크를 제외했습니다. 예제에 대한 정규화 결과이며 실제 사용자 계정의 잘못된 공고를 확인했다는 의미는 아닙니다.

응답 JSON 배열의 `dsSch`·`resHeader`·`dsList`를 처리합니다. 성공 `SS_CODE=Y`, 제공된 요청 정보·페이지 크기·순번·행별 전체 수·복합 식별자 중복·선택 유형/상태를 검증합니다. 한 요청은 한 페이지만 조회합니다. 빈 `dsList`는 `no_data`지만 전체 수가 행에만 실려 있으므로 `totalCount: null`입니다. 빈 페이지를 전체 공고 부재로 단정하지 않습니다.

## 실패와 검증 상태

실제 무효 시험 키는 **HTTP 403·JSON 게이트웨이 코드 30**을 반환했습니다. `AUTH_REQUIRED`·`awaiting_auth`로 보존하고 키·승인을 수정한 뒤 같은 작업을 재개할 수 있습니다. HTTP 200의 JSON/XML 게이트웨이 인증 오류도 처리합니다. 정상 자료는 문서의 JSON만 지원합니다.

한도(`22`·`23`·HTTP 429), IP 차단(`29`), 알 수 없는 코드·LH 비성공 헤더·연결/시간 초과를 구분합니다. 원문 공급자 오류·키 URL은 반환하지 않습니다. 30초 제한·취소·2MB 스트림 제한·UTF-8·JSON 구조를 검사하고 XML DTD/엔티티는 거절합니다. 공급자 내용은 엔진에서 `external_data`로 표시합니다.

모의 단위/HTTP·모바일 크기 화면·Linux·가이드 예제 정규화·실제 HTTPS 오류의 범위는 [검증 기록](VALIDATION.md#2026-10-20-lh-공고-조회-검증)에 구분합니다. 본인 키의 정상/빈 응답·날짜/지역/상태 필터·페이지/순번·복합 ID·상세 링크·한도와 실제 휴대폰 기기 검증은 남아 있습니다. 모의·문서 예제·무효 키 오류로 지원 수를 올리지 않습니다.

후속 LH 기능은 공고별 공급정보·첨부 원문 조회입니다. 별도 공식 서비스·키·식별자 규격을 확인해야 합니다. 다음 신규 후보는 **KOSIS 지역통계**의 첫 지표·표 ID·단위·시점·키/HTTPS·호출 제한 확인입니다. [작업 체크리스트](../TODO.md)
