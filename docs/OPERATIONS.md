# 운영과 문제 해결

## 시작·종료

`npm.cmd start`로 시작하고 터미널에서 Ctrl+C로 종료합니다. 실행 중인 작업에 취소를 요청하고 브라우저·HTTP 서버·DB를 닫습니다. 중단 순간 이미 전송된 쓰기는 다음 실행에서 실제 결과 확인이 필요할 수 있습니다.

한 데이터 경로는 한 프로세스만 사용합니다. 다른 포트에서 별도 엔진을 실행하려면 별도 `--data-dir`도 지정하세요. 비정상 종료로 남은 잠금은 해당 프로세스가 없음을 확인했을 때 다음 시작에서 복구합니다.

## 저장 위치와 백업

기본 `.koreai`에는 `koreai.sqlite`, SQLite WAL/SHM 파일, 실행 잠금, 전용 브라우저 프로필이 있습니다. 작업 본문·조회 결과도 개인 정보를 포함할 수 있습니다. 공개 코드와 분리되어 `.gitignore`에 포함됩니다.

일관된 백업은 엔진 종료 후 데이터 폴더 전체를 복사해 만드세요. 실행 중 DB 파일 하나만 복사하면 WAL의 최근 작업이 누락될 수 있습니다. DPAPI 비밀정보는 원래 Windows 사용자 환경과 함께 보호됩니다. 다른 장치로 옮길 때는 새로 계정을 연결하는 것을 기본으로 합니다.

알파 버전은 보관 기간에 따른 자동 삭제를 제공하지 않습니다. 사용자 기기에 작업 이력과 멱등키를 유지합니다. 민감한 시험 데이터는 별도 `--data-dir`로 분리하세요. 계정 연결 해제는 저장된 비밀 키와 해당 연결을 제거하지만 이미 기록한 작업 본문·결과를 소급 삭제하지 않습니다. 브라우저 프로필도 별도 저장소입니다.

## 흔한 문제

| 증상 | 확인할 항목 |
|---|---|
| PowerShell에서 npm.ps1 실행 거부 | `npm` 대신 `npm.cmd` 사용 |
| `node:sqlite`를 찾지 못함 | Node 22.17 이상인지 확인 |
| 4318 포트 사용 중 | 이전 엔진 종료 또는 다른 포트·데이터 경로 사용 |
| 연결 코드가 만료됨 | 엔진 재시작 후 새 관리 화면 주소 사용 |
| 행동이 비활성 | 올바른 계정 종류, 필수 키, 행동 권한, 운영 중단 여부 확인 |
| OAuth 실패 | 개발자 앱 설정·콜백 주소·권한·Client Secret 확인 |
| `인증 필요` | 계정 토큰 갱신 또는 재로그인 후 작업 재개 |
| 브라우저를 열 수 없음 | Chrome·Edge 설치, `--channel chrome` 또는 `msedge` 확인 |
| `결과 확인 필요` | 공급자 화면에서 글·일정·메시지 생성 여부 확인 후 결과 기록 |
| DPAPI 복호화 실패 | 등록한 Windows 사용자로 실행하거나 계정 키 재등록 |
| 실제 검증 수가 0 | 문서·모의 검증은 실제 계정 성공으로 집계하지 않음 |

## 지원 중단과 업데이트

공급자 정책·페이지·API 변경으로 오작동하면 관리 화면의 `검증과 운영`에서 해당 행동을 중단합니다. 대기 작업은 취소하고 이미 전송된 쓰기는 결과 확인 상태로 남길 수 있습니다. 수정 후 커넥터 버전을 올리고 모의·실제 검증을 다시 수행하세요.

의존성 업데이트는 잠금 파일과 함께 검토하고 `check`, `build`, `test`를 통과한 뒤 적용합니다. 자동 플러그인 다운로드와 원격 코드 업데이트는 없습니다.

## 오류 보고

오류 보고에는 다음을 포함합니다.

- KoreAI·Node·Windows·Chrome/Edge 버전.
- 행동 ID와 커넥터 버전, 문제 발생 시각, 모의/실제 검증 여부.
- 작업 상태·오류 코드와 예상 동작, 재현 순서.
- 비밀정보와 개인 내용이 제거된 화면 또는 입력 예제.

API 키·접근 토큰·쿠키·일회용 연결 코드·전체 DB·브라우저 프로필은 보고에 첨부하지 않습니다. 문제가 외부 게시·전송에 영향을 주면 자동 재요청보다 공급자의 실제 결과 확인을 먼저 수행합니다.
