# TMAP 자동차 경로·소요시간

확인일: **2026-10-21**. 공식 자동차 경로안내 v1의 **요약 조회 한 건**을 구현했습니다. 사용자 소유 TMAP 앱 키가 필요합니다. 소비자 TMAP 로그인·저장 장소·실제 내비게이션 조작은 포함하지 않습니다.

## 연결과 사용

1. [SK open API TMAP 상품](https://openapi.sk.com/products/detail?svcSeq=4)에서 가입·상품 사용 신청 후 본인 앱 키를 발급받습니다. 계정의 실제 상품 권한·요금제·IP/도메인 조건을 확인합니다.
2. KoreAI **연결 계정 → 계정 연결 → TMAP 자동차 경로**에서 `appKey`를 등록하고 **TMAP 자동차 경로·소요시간 조회**를 허용합니다. 다른 공급자의 키와 구분합니다.
3. **확장 계획 → TMAP → 조회 기능 열기 → 예시 입력 불러오기**를 누르고 좌표를 수정합니다.
4. **요청 구조 미리보기**는 키 조회·외부 전송 없이 동작합니다. **실행 요청**으로 조회하고 작업 결과를 확인합니다.

DeepSeek 새 대화의 허용 기능에 TMAP 행동을 선택하거나, 해당 행동·계정만 허용한 HTTP/MCP 클라이언트를 사용할 수 있습니다. 기존 대화의 권한은 자동 확대하지 않습니다. 실행 시 출발·목적지 좌표는 TMAP 서버로 전송됩니다.

## 입력

행동 ID: `tmap.route.car`. 다음은 형식 예시이며 실제 경로 성공을 확인한 좌표는 아닙니다.

```json
{
  "start": { "longitude": 126.978, "latitude": 37.5665 },
  "end": { "longitude": 127.0276, "latitude": 37.4979 },
  "preference": "recommended"
}
```

- 좌표는 **WGS84 경도·위도 숫자**입니다. 카카오 장소 검색의 `x`가 경도, `y`가 위도이면 숫자로 변환해 사용할 수 있습니다. KATEC·TM 좌표를 넣지 않습니다.
- 초기 입력 범위는 경도 124~132·위도 33~39입니다. 이 사각 범위 검사는 실제 한국 도로·경로 지원 판정이 아닙니다. 같은 출발/목적 좌표는 거절합니다.
- `preference`는 `recommended`(기본·교통최적+추천), `avoid_tolls`(무료우선), `fastest`(최소시간) 중 하나입니다. 무료우선도 실제 요금 0을 보장하지 않습니다.
- `appKey`·임의 URL·공급자 옵션·미래 출발 시각·경유지는 입력받지 않습니다. 승용차 `carType=0`, `totalValue=2`로 고정합니다. 한 작업은 경로 조회 한 번만 전송하며 다른 옵션을 자동 비교하지 않습니다.

실제 요청은 `POST https://apis.openapi.sk.com/tmap/routes?version=1`입니다. 키는 `appKey` 헤더에만 넣고 좌표·옵션은 `application/x-www-form-urlencoded` 본문에 넣습니다. JSON 미리보기의 `body`는 이 폼의 필드 표현입니다. 리다이렉트·자동 재시도는 사용하지 않습니다.

## 결과

| 필드 | 의미 |
|---|---|
| `distanceMetres` | 제공 거리, m |
| `durationSeconds` | 조회 시점의 예상 소요시간, 초 |
| `providerTotalFareKrw` | 공급자가 제공한 경로 총 요금 값, 원. 0과 미제공 `null` 구분 |
| `taxiFareEstimateKrw` | 제공된 택시 예상 요금, 원. 실제 결제액 아님 |
| `retrievedAt`·`expiresAt` | 조회 시각·결과 데이터의 사용기한 |
| 작업의 `resultExpiresAt` | 엔진이 적용하는 사용기한. 작업 시작 기준으로 더 일찍 만료될 수 있음 |
| `providerUpdatedAt`·`arrivalTime` | 미제공 `null`. 실제 자료 갱신일·도착 시각을 추정하지 않음 |
| `responseIdentityVerified` | `false`. 요약 응답에는 대상 좌표가 없어 입력과 일치 대조하지 못함 |

출처를 결과와 함께 표시합니다. 도로 형상·단계별 주행 지시·실시간 운행·유류비·주차비·할인·예약을 제공하거나 합산하지 않습니다. 다른 좌표인데 거리/시간이 0이거나 HTTP 204이면 `결과 확인 필요`로 중단하며 성공 증거를 만들지 않습니다. 응답 구조 변경·잘못된 단위·중복 요약·초과 본문·잘못된 UTF-8도 중단합니다. 시간 제한은 30초, 요약 응답은 최대 256KB입니다.

## 요금과 결과 사용기한

[공식 요금표](https://openapi.sk.com/products/calc?menuSeq=5&svcSeq=4)는 경로안내 Free 일 1,000건, Lite 월 2,200,000원·일 10,000건, Premium 건당 11원(VAT 포함)을 안내합니다. 실제 적용 상품·공유 사용량·계약은 본인 콘솔에서 확인하세요. KoreAI가 유료 상품에 가입하거나 요금제를 변경하지 않습니다. 429는 한도 오류, 401/403은 키·상품 권한 확인을 위한 인증 대기입니다.

[TMAP 약관](https://tmapapi.tmapmobility.com/terms.html)은 저장 후 24시간 이상 데이터 사용을 제한합니다. 이 연결은 작업 시작부터 24시간을 상한으로 적용합니다.

- 작업 조회·목록·중복 요청·엔진 재시작 시 만료한 결과 본문을 SQLite 기록에서 제거하고 `RESULT_EXPIRED` 사유를 표시합니다. 과거 성공 상태·실행 이력은 남습니다.
- 같은 멱등키를 다시 요청해도 자동 재조회하지 않습니다. 새 작업을 요청해야 새 호출이 발생합니다.
- 해당 작업을 포함한 대화는 조회/재개 시 이후의 AI 응답을 만료 안내로 바꾸고 모델용 프로토콜을 제거합니다. 사용자 메시지·그 이전 응답은 보존하고 새 대화를 안내합니다.
- 만료 정리는 접근/재시작 시 수행합니다. 외부 클라이언트에 전달된 사본·백업의 사용기한은 해당 운영 환경에서도 지켜야 합니다.

## 검증과 후속 기능

전용 테스트는 모의 요약·권한·인증/한도·취소·만료·대화 재전송 차단을 확인합니다. 모바일 크기 UI에서 계정 등록 → 미리보기 → 조회 → 만료 결과 제거를 검증했습니다. 별도 시험 DB와 무효 키의 **실제 공식 서버 HTTP 403 → `awaiting_auth`**도 확인했으며 지원 실적은 늘리지 않았습니다. 본인 키의 정상/빈 경로·요금/한도 검증과 실제 GCP·휴대폰 사용은 남아 있습니다. [검증 기록](VALIDATION.md#2026-10-21-tmap-자동차-경로-조회-검증)
