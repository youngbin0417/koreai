# 에어코리아 대기질 예보

문서 확인·구현일: **2026-10-14**. 행동 ID는 `airkorea.forecast`, 계정 종류는 `airkorea-api`입니다. [공식 대기오염정보 API](https://www.data.go.kr/data/15073861/openapi.do)의 예보통보 조회 규격을 사용합니다.

## 연결과 실행

1. 공공데이터포털에서 **한국환경공단 에어코리아 대기오염정보**를 활용 신청합니다.
2. **연결 계정 → 계정 연결 → 에어코리아 대기질 예보**에서 일반 인증키(Decoding)를 등록하고 조회 행동을 허용합니다.
3. **확장 계획 → 에어코리아 → 조회 기능 열기 → 예시 입력 불러오기**를 선택합니다.
4. 발표 날짜와 항목을 확인한 뒤 **실행 요청**을 누릅니다. **요청 구조 미리보기**는 키 조회·외부 호출 없이 동작합니다.

```json
{"date":"2026-10-14","pollutant":"PM25"}
```

`date`는 Asia/Seoul 기준 **발표 날짜**입니다. `pollutant`는 `PM10`(미세먼지), `PM25`(초미세먼지, 기본값), `O3`(오존) 중 선택합니다. 예시는 한국 표준시의 오늘 날짜이며 해당 날짜의 예보 존재를 보증하지 않습니다.

공식 규격에서 날짜 조회에는 페이지 번호·결과 수가 적용되지 않습니다. 초기 초안의 `page`·`limit`은 제거했고 이 필드를 입력하면 거절합니다. 날짜와 항목으로 반환된 예보 통보들을 전달합니다.

연결한 계정은 **AI 대화**의 새 대화에서 이 조회 행동을 선택해 사용할 수도 있습니다. HTTP·MCP는 기존 행동 실행 인터페이스를 사용합니다.

## 결과

| 필드 | 의미 |
|---|---|
| `dataKind` | `forecast`; 예보 정보 |
| `announcementDate` | 요청한 발표 날짜 |
| `forecasts[].dataTime` | 공급자 원문 발표 시각 |
| `forecasts[].informData` | 예보 대상 날짜; 다음 날 이후일 수 있음 |
| `forecasts[].informCode` | 요청 항목과 일치하는 예보 항목 |
| `forecasts[].informGrade` | 지역별 예보 등급 원문 |
| `forecasts[].informOverall` / `infornOverall` | 공급자가 반환한 필드명의 예보 개황 원문 |
| `forecasts[].informCause`, `actionKnack` | 제공된 발생 원인·행동요령 원문 |
| `source` | 한국환경공단 에어코리아 출처·공식 URL·이용 조건 |

등급·개황·원인·행동요령은 원문과 공백을 보존합니다. 출처의 이용 조건은 공공누리 제3유형(출처표시·변경금지)으로 결과에 함께 전달합니다. 현재 측정소 관측값 조회는 후속 행동입니다.

`status: no_data`는 해당 발표 날짜·항목의 자료가 없다는 뜻입니다. 정상 형식이 아닌 응답과 날짜·항목 불일치는 `INVALID_RESPONSE`로 실패합니다. 인증 오류는 `awaiting_auth`로 보존하며 계정 키·권한을 확인한 뒤 재개합니다. 한도 초과·IP 접근 거절·통신 실패·취소는 각각 구분합니다.
