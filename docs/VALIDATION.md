## 2026-10-11 확장 초안 검증

타입 검사와 빌드를 통과했습니다. 앱·API 확장 초안 추가 후 Windows 전체 테스트는 **60개 중 58개 통과·Linux 전용 2개 제외·실패 0개**입니다. 새 테스트는 후보 26개·초안 6개, 요청 매핑·입력 검증, 계정/권한 등록 후에도 실행 차단, 관리자 미리보기와 공급자 호출 미수행을 확인합니다. 기존 Linux 전체 검증은 53개 중 52개 통과·Windows 전용 1개 제외였으며, 최근 변경은 별도 Linux 검증으로 구분합니다.

새 확장 화면은 실제 Edge에서 후보 검색·우선순위 필터·예시 입력·JSON 요청 미리보기·입력 오류·미구현 요청 매핑 표시를 통과했습니다. 초안을 추가한 뒤에도 구현된 API 행동 표시가 20을 유지하며 실행 버튼이 비활성 상태입니다. 390px 화면의 가로 넘침과 JavaScript 오류도 없었습니다. 캡처: `.test-data/screenshots/expansion-mobile.png`.

**새 초안의 Linux 검증: 통과.** WSL2 Ubuntu·Node.js 22.17.0에서 동일한 확장 테스트 원본을 임시 JavaScript로 변환해 빌드된 서버를 대상으로 실행했고 **4개 모두 통과**했습니다. 데이터 폴더는 Linux 파일 권한을 지원하는 OS 임시 디렉터리를 사용했습니다. 기존 다섯 기본 연결도 생산용 Linux AES-256-GCM 저장소에서 대기·재개·재시작 유지 흐름을 다시 통과했습니다. 이 검증은 공급자 호출이나 Linux의 새 화면 브라우저 시험을 포함하지 않습니다.

Linux 시험은 별도 임시 작업공간에서 실행했습니다. 부족한 Chromium 라이브러리는 Ubuntu 패키지를 다운로드·추출하고 `LD_LIBRARY_PATH`로 연결했으며 시스템 패키지를 변경하지 않았습니다. 실제 설치에서는 `npx playwright install --with-deps chromium`을 사용합니다. `doctor --browser-smoke`의 실제 Chromium 실행도 통과했습니다.

DeepSeek 공식 `/models`가 `deepseek-flash`를 **DeepSeek-V4.1-Flash**로 반환했고, 실제 Responses API 요청이 `OK`를 반환했습니다. 프로젝트 API 테스트 실행기는 `npm run ai:test`이며 실제 모델의 도구 호출을 KoreAI HTTP API에 연결합니다. 실행별 결과와 모델 호출 수·도구 기록은 `.test-data/deepseek-live/`의 JSON 보고서에 보관합니다.

**실제 DeepSeek → KoreAI 실행: 통과.** 2026-10-10, Windows·Edge headless에서 V4.1 Flash를 6회 호출했습니다. 모델이 기능 검색·작업 생성·작업 상태 조회를 실제 HTTP로 수행했고, 시험 사이트 읽기 → 게시 승인 대기 → 시험 관리자 승인 → 게시 영수증 확인 → 새 페이지에서 제목·내용 확인을 통과했습니다. 에이전트의 승인 요청은 HTTP 403으로 차단됐으며, 같은 멱등키의 재요청에서도 게시글은 1개였습니다. 보고서: `.test-data/deepseek-live/2026-10-10T10-41-43-458Z-d2e41716.json`.

LLM과 HTTP·브라우저는 실제 실행했고, 대상 사이트는 운영자 소유 시험 사이트입니다. 국내 서비스 공급자의 실제 계정 호출을 검증한 결과는 아니며 실제 지원 서비스 집계는 0을 유지했습니다. 키·관리 세션·클라이언트 토큰은 보고서에서 제거하고 모델 대화의 추론 내용은 저장하지 않았습니다.

**다섯 기본 커넥터 실제 모델 테스트: 통과.** 2026-10-11, V4.1 Flash 6회 호출로 강남언니·당근마켓·마켓컬리·쿠팡·토스의 연결 상태 조회와 진입 안내 10개 작업을 생성하고 결과를 조회했습니다. 준비 상태·고정 URL·외부 실행 미수행·지원 실적 제외를 확인했습니다. 보고서: `.test-data/deepseek-live/2026-10-11T12-45-51-348Z-d019a2cc.json`. 초기 시도에서 발견한 호출 한도와 생성·조회 도구 경계를 조정한 뒤 재검증한 결과입니다.
