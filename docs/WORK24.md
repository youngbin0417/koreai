# 고용24 채용공고 조회

확인일: **2026-10-21**. 공식 채용정보 목록 API를 연결했습니다. **기업회원의 API 신청·심사와 승인 키가 필요**하며, 정상 공고 조회의 실제 계정 검증은 대기입니다. [공식 명세](https://www.work24.go.kr/cm/e/a/0110/selectOpenApiSvcInfo.do?apiSvcId=000000000000000000000000000060&fullApiSvcId=000000000000000000000000000000%5E000000000000000000000000000001&upprApiSvcId=000000000000000000000000000059), [가입·신청 안내](https://www.work24.go.kr/cm/e/a/0110/selectOpenApiIntro.do)

## 연결과 사용

1. 고용24 기업회원으로 가입·로그인하고 채용정보 Open API를 신청합니다. 심사를 통과해 발급받은 인증키와 승인 범위·이용 조건을 확인합니다.
2. KoreAI **연결 계정 → 계정 연결 → 고용24 채용정보**에서 `authKey`와 **고용24 채용공고 찾기** 권한을 저장합니다.
3. **확장 계획 → 고용24 → 조회 기능 열기**에서 사용할 계정을 선택하고 **검색어**를 입력합니다. 지역 이름/코드로 목록을 좁혀 근무지역을 선택하고, 필요하면 고용형태와 페이지/건수를 지정합니다. JSON 작성은 필요하지 않습니다.
4. **요청 구조 미리보기**로 키 없이 구조를 확인한 뒤 **실행 요청**을 누릅니다. 조회 시 검색어·지역 코드·고용형태가 고용24에 전송됩니다.

DeepSeek 새 대화의 허용 기능이나 HTTP/MCP 클라이언트의 행동·계정 범위에도 이 조회를 지정할 수 있습니다. 개인회원 로그인, 공공데이터포털 키, LLM 키는 이 인증키를 대신할 수 없습니다.

검색어·지역·고용형태를 바꾸면 1페이지로 돌아갑니다. **예시 입력 불러오기**로 기본 조건을 채울 수 있고 **JSON 입력**의 편집도 폼에 반영됩니다. 잘못된 JSON·검색어·코드 형식·페이지/건수는 실행 전에 안내하며 최종 입력·권한 검증은 서버가 수행합니다. 계정을 선택하지 않으면 실행할 수 없습니다.

## 입력과 반환값

행동 ID는 `work24.jobs.search`, 커넥터는 `work24-jobs-api`, 계정 종류는 `work24-api`입니다.

```json
{
  "keyword": "개발자",
  "page": 1,
  "limit": 10
}
```

| 입력 | 범위 |
|---|---|
| `keyword` | 필수 1~100자, 앞뒤 공백 제거. 쉼표·파이프·제어문자 제외 |
| `regionCode` | 선택, 근무지역 코드 5자리 문자열. 화면은 검토한 공식 XLS 285개 목록을 검색/선택하며 생략하면 지역 필터를 보내지 않음 |
| `employmentType` | 선택, `10` 기간의 정함 없음, `11` 그 단시간, `20` 기간의 정함 있음, `21` 그 단시간 |
| `page` / `limit` | 1~1,000 / 1~100, 기본 1 / 10 |

### 지역·고용형태 근거

2026-10-21에 [채용정보 공식 명세](https://www.work24.go.kr/cm/e/a/0110/selectOpenApiSvcInfo.do?apiSvcId=000000000000000000000000000060&fullApiSvcId=000000000000000000000000000000%5E000000000000000000000000000001&upprApiSvcId=000000000000000000000000000059)와 이 명세가 연결한 [지역 코드표 XLS](https://openapi.work.go.kr/opi/opi/common/useApi/apiCdList.do?cdGbn=region)를 재확인했습니다. XLS의 285개 코드·이름을 원문대로 등록했습니다. `11680`은 서울 강남구이며 `00000`의 선행 0을 보존합니다. **지역 조건 없음**은 필터 생략이고 **지역무관(00000)**은 공급자의 별도 코드입니다. 지역 목록 검색만으로 서버에 요청하지 않으며 검색어가 바뀌어도 선택 지역을 유지합니다.

등록 자료는 [work24-reference.ts](../src/research/work24-reference.ts)에 있습니다. 검토한 파일은 33,792바이트, SHA-256 `e6a12559b3a74aef363861156f7e15c78f2de759d22fc155fbe07c2baab63eae`입니다. 다운로드 파일의 이번 지문이며 공급자의 영구 버전 식별자가 아닙니다. 목록은 자동 갱신하지 않으며 공급자 이름·코드를 임의 변환하지 않습니다. 기존 HTTP/MCP의 5자리 입력도 유지합니다. JSON에 목록 밖의 유효한 5자리 코드를 넣으면 입력을 보존하고 코드표 미확인 안내를 표시합니다.

고용형태 선택은 기존 행동의 `10/11/20/21` 네 코드입니다. 명세의 파견·대체인력·다중 조건 등은 후속 범위로 남깁니다. 현재 요청은 `empTpGb`를 지정하지 않으므로 명세의 기본 채용구분인 상용직 검색을 사용합니다. ‘고용형태 조건 없음’이 모든 종류의 공고를 보장하는 것은 아닙니다.

[공통코드 지역 API](https://www.work24.go.kr/cm/e/a/0110/selectOpenApiSvcInfo.do?apiSvcId=000000000000000000000000000070&fullApiSvcId=000000000000000000000000000094%5E000000000000000000000000000069)는 별도 고정 경로 `callOpenApiSvcInfo21L01.do`와 `target=CMCD`, `dtlGb=1`, `authKey`를 안내합니다. 이번 화면은 검토한 정적 XLS 목록을 사용하며 이 API를 자동 호출하거나 기존 계정에 새 권한을 부여하지 않습니다. 실제 목록 API의 정상 계정 호출·공통코드 이용 승인도 별도 확인 대상입니다.

### 결과 카드

회사·공고명·근무지역·임금형태·급여·등록일/마감 원문과 확인된 공식 공고 링크를 먼저 표시합니다. **근무조건·공고 원문 더 보기**에서 최소/최대 급여, 근무형태, 경력/학력, 수정 시점·제공처를 확인합니다. 빈 값은 **미제공**, `0`과 선행 0은 원문 그대로 표시합니다. 공급자 원문 날짜를 한국 시간으로 해석하거나 정규화하지 않으며 **조회 시각**만 한국 시간으로 표시합니다. 없는 과거 조회 시각은 **기록 없음**입니다.

**첫/이전/다음 페이지**는 원래 작업의 계정·검색 조건·건수를 보존한 새 읽기 작업입니다. 페이지마다 공급자를 새로 조회하므로 결과가 달라질 수 있습니다. 전체 0건과 빈 페이지를 구분하고 짧은 중간 페이지·1,000페이지 상한을 안내합니다. 인증 대기는 기존 작업에서 키/승인을 확인한 뒤 **재개**합니다. 요청/결과의 JSON 상세와 모르는 과거 결과의 원문도 유지합니다.

`jobs`에는 구인인증번호·회사·공고명·근무지역·급여·경력/학력·등록일·마감일 원문과 검증 가능한 출처 링크를 반환합니다. 급여의 선행 0·`0`·빈 값·임금형태를 보존하고 연봉/월급 환산이나 숫자 비교는 하지 않습니다. `normalizedAmount`, `normalizedUnit`, `currentlyAcceptingApplications`는 `null`입니다. `채용시까지` 등 날짜 문구로 현재 모집 여부를 추정하지 않습니다.

페이지·요청 건수·전체 수·ID 중복·제공된 고용형태를 검사합니다. `no_data`는 전체 0건, `empty_page`는 전체 결과 이후의 빈 페이지입니다. 제공 요약만으로 검색어·지역 필터 전체 일치를 확정할 수 없어 `queryMatchVerified`는 `false`입니다. 짧은 중간 페이지는 `partialPage`로 표시하며 전체 목록을 조회했다고 보장하지 않습니다.

원문 URL은 공식 호스트의 HTTPS·같은 구인인증번호·비밀정보 없는 쿼리일 때만 제공합니다. HTTP·외부 주소·ID 불일치는 `url: null`로 남기고 자동 열기·상세 수집은 하지 않습니다. 목록의 사업자등록번호·상세 주소·불필요한 필드는 저장 결과에서 제외합니다. 공고 내용은 외부 데이터이며 권한·승인 규칙을 바꾸는 지시로 사용하지 않습니다.

## 요청·오류 처리

고정 HTTPS 목록 경로 `https://www.work24.go.kr/cm/openApi/call/wk/callOpenApiSvcInfo210L01.do`에 GET 요청합니다. `callTp=L`, `returnType=XML`, `startPage`, `display`, `keyword`, `sortOrderBy=DESC`와 선택 필터만 보냅니다. 키는 실행 시 `authKey` 쿼리에 한 번 인코딩해 넣고 미리보기·일반 로그·에이전트 응답에는 제공하지 않습니다. 공급자의 쿼리 키 방식이므로 운영 프록시에서도 해당 쿼리를 기록하지 않아야 합니다.

리다이렉트·자동 재시도를 금지하고 30초·2MB 상한, UTF-8/XML·외부 엔티티 검사를 적용합니다. HTTP 401/403은 인증 대기, 429는 한도 오류입니다. HTTP 200이라도 검토한 `GO24` 서비스 미등록 오류이면 `WORK24_SERVICE_ACCESS_REQUIRED`와 `awaiting_auth`로 보존합니다. 키·서비스 승인을 확인한 뒤 재개합니다. 알 수 없는 공급자 오류는 본문을 노출하지 않고 `WORK24_PROVIDER_ERROR`로 실패합니다.
