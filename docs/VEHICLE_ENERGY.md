# 전기차 충전소·주유소 찾기

확인일: **2026-10-20**. 전기차 충전소 1개·오피넷 3개 조회 행동, 별도 계정 두 종류, 요청 미리보기와 모바일 화면을 구현했습니다. **본인 키의 정상 응답 검증은 대기**입니다. 실제 무효 키 응답·모의 성공은 실사용 지원으로 집계하지 않습니다.

## 전기차 충전소 연결

1. 공공데이터포털의 [한국환경공단 전기자동차 충전소 정보](https://www.data.go.kr/data/15076352/openapi.do)를 활용 신청합니다.
2. KoreAI **연결 계정 → 전기차 충전소 정보**에 일반 인증키 **Decoding** 값을 `serviceKey`로 등록하고 **전기차 충전소 찾기**를 허용합니다.
3. **확장 계획 → 전기차 충전소 → 조회 기능 열기**에서 예시를 불러와 실행합니다. API 실행만 사용하면 Linux에 그래픽 브라우저가 필요하지 않습니다.

### 입력 예시

`ev-chargers.search` — 서울 강남구의 충전기 첫 페이지:

```json
{"provinceCode":"11","districtCode":"11680","page":1,"limit":100}
```

| 입력 | 의미 |
|---|---|
| `provinceCode` | 필수. 가이드 v1.25의 시도 코드. 아래 목록 참조 |
| `districtCode` | 선택. `zscode` 5자리. 예: 강남구 `11680`, 앞 두 자리는 시도와 일치 |
| `stationId` | 선택. 조회 결과의 충전소 ID, 영문/숫자 최대 8자리 |
| `page`·`limit` | 기본 1·100. 페이지 최대 1000, 개수 10~1000 |
| `name` | 선택. **받은 한 페이지 안에서만** 충전소명 부분일치 |
| `chargerType` | 선택. **받은 한 페이지 안에서만** 타입 코드 일치 |
| `includeDeleted` | 기본 false. 최근 삭제된 충전기 기록을 제외. true면 삭제 여부와 함께 포함 |

시도: 서울 `11`, 전남광주 `12`, 부산 `26`, 대구 `27`, 인천 `28`, 대전 `30`, 울산 `31`, 세종 `36`, 경기 `41`, 충북 `43`, 충남 `44`, 경북 `47`, 경남 `48`, 제주 `50`, 강원 `51`, 전북 `52`. **오피넷·KOSIS 코드와 다릅니다.** 시군구의 최신 코드는 아래 공식 첨부 가이드에서 확인하세요.

타입: `01` DC차데모, `02` AC완속, `03` 차데모+AC3상, `04` DC콤보, `05` 차데모+DC콤보, `06` 차데모+AC3상+DC콤보, `07` AC3상, `08` DC콤보(완속), `09` NACS, `10` DC콤보+NACS, `11` DC콤보2(버스전용). 타입 코드만으로 특정 차량의 어댑터·충전 호환성을 확정하지 않습니다.

### 결과 읽기

- `chargers`: 충전기 단위 목록. `stationId:chargerId` 복합 키로 중복을 검사합니다. 같은 충전소에 여러 충전기가 있을 수 있습니다.
- 주소·상세 위치·WGS84 위경도·운영기관/전화·이용시간·충전용량 원문을 반환합니다. 0 또는 없는 좌표는 미확인으로 표시합니다.
- `reportedStatusCode`·`reportedStatusName`: 공급자가 보고한 상태입니다. 코드 `2`는 **충전대기**, `3`은 충전중, `6`은 예약중입니다. 도착 시 충전 가능은 `availableOnArrival: null`로 둡니다.
- `statusUpdatedAtRaw`: 공급자 상태 변경/통신 변경 시각 14자리 원문. 확인 시각이나 현재 시각과 다르며 시간대를 추정하지 않습니다. 모두 0 또는 빈 값은 미확인입니다.
- `restricted`·`restrictionDetail`, `deleted`·`deletionDetail`, `parkingFree`·`note`를 함께 확인합니다. 상태가 대기여도 출입 제한·철거·안내 문구가 있을 수 있습니다. 빈 Y/N 값은 false로 추정하지 않습니다.
- `pagination.totalChargerCount`는 **충전기 수**입니다. `providerRows`는 받은 행, `returnedCount`는 페이지 내부 필터 적용 후 행입니다. 이름·타입으로 결과가 없어도 `nextPage`를 확인하세요. 지역 전체에서의 부재·가장 가까운 충전소를 의미하지 않습니다.
- 지역·충전소 ID·페이지/전체 수·좌표·상태 시각을 대조합니다. 시군구 값이 응답에 없으면 `districtFilterCheck: not_reported`로 구분합니다.

충전 요금·차량 연결·예약/결제·경로/거리순 검색은 후속 행동입니다. 현재 위치를 휴대폰에서 자동 수집하지 않습니다.

### 공식 명세의 확인 사항

기준은 [공식 첨부 가이드 v1.25, 2026-07-01](https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000003680003&fileDetailSn=1)입니다. `getChargerInfo`의 지역/ID 요청과 **평면 JSON**, XML `response/header`의 페이지/전체 수를 처리합니다. HTTPS만 호출합니다. 문서의 HTTP 예시를 그대로 쓰지 않습니다.

가이드의 `statId`·`chgerId`는 필수로 표기됐지만 같은 문서의 목록 요청 예시에는 둘 다 없습니다. 첫 목록 조회에서는 둘을 생략하고 선택한 충전소 ID만 전달할 수 있게 구현했으며 **이 차이와 실제 필수 여부는 본인 키의 정상 응답으로 확인해야 합니다.** 표준 JSON 구조 변경·다른 페이지 메타데이터는 임의로 성공 처리하지 않습니다.

실제 HTTPS 무효 시험 키는 **HTTP 403 / 게이트웨이 코드 30**이었고 엔진은 `awaiting_auth`로 처리합니다. 키/승인을 고친 뒤 같은 작업을 재개할 수 있습니다. 사용 중인 키의 호출 한도는 포털에서 확인하세요. 결과 출처 표시는 한국환경공단 공공데이터포털 정보로 제공합니다.

## 주유소 연결: 오피넷

1. [오피넷 유가정보 API 안내](https://www.opinet.co.kr/user/custapi/custApiInfo.do)에서 일반 API 이용을 신청하고 본인 인증키를 발급받습니다. **공공데이터포털 키와 다릅니다.**
2. **연결 계정 → 오피넷 주유소**에서 `apiKey`를 등록하고 원하는 세 행동을 허용합니다.
3. **확장 계획 → 오피넷 주유소**에서 **지역코드 → 저렴한 주유소 → 상세·가격** 순서로 실행합니다. 각 단계는 사용자가 명시적으로 요청하며 자동으로 연속 호출하지 않습니다.

### 1. 오피넷 지역코드 찾기

`opinet.regions.list` — `{}`는 시도, 아래 예시는 서울의 시군구:

```json
{"provinceCode":"01"}
```

`regions[].code`와 이름을 반환합니다. 시도 2자리·시군구 4자리와 앞자리/중복을 검사하고 선행 0을 보존합니다. 예: 서울 `01`, 강남구 `0113`. 충전소의 서울 `11`·강남구 `11680`과 혼용하지 않습니다. [공식 지역코드 API](https://www.opinet.co.kr/user/custapi/openApiInfoDtl.do?apiId=5)

### 2. 지역별 저렴한 주유소 찾기

`opinet.stations.cheapest` — 지역코드 조회에서 선택한 코드를 사용합니다:

```json
{"areaCode":"0113","product":"B027","limit":10}
```

`areaCode` 필수(2/4자리), `product`는 휘발유 `B027` / 경유 `D047` / 고급휘발유 `B034`, `limit`는 1~20입니다. 공급자의 저가순 후보에서 ID·주소·상표·가격(원/리터)·순위를 반환합니다. 중복·가격 역순·보고된 지역 불일치를 검사합니다. 0 가격은 무료로 해석하지 않고 미확인입니다. 지역 값이 보고되지 않으면 필터 대조 여부도 미확인으로 표시합니다. [공식 저가순 API](https://www.opinet.co.kr/user/custapi/openApiInfoDtl.do?apiId=2)

### 3. 주유소 상세·유종별 가격 조회

`opinet.stations.get` — 앞 단계 결과의 ID 사용:

```json
{"stationId":"A0010207"}
```

주소·전화·세차장/정비/편의점 등 시설·유종별 가격을 반환합니다. 응답 ID와 요청 ID를 대조하고 유종별 `tradeDateRaw`·`tradeTimeRaw`를 따로 보존합니다. 목록에는 가격 기준 일시가 없으므로 상세에서 확인하세요. 현재 영업·유류 재고·실제 결제가는 미확인입니다. [공식 상세 API](https://www.opinet.co.kr/user/custapi/openApiInfoDtl.do?apiId=1)

공식 표의 상표 필드 `POLL_DIV_CD`와 예제 `POLL_DIV_CO`를 둘 다 인식하며 충돌하면 중단합니다. 반환 좌표는 **KATEC** 원문입니다. 지도에 WGS84 경위도로 넣지 않으며 변환 검증 후 반경/거리순 기능을 추가할 예정입니다. 일부 다른 유종의 문서 코드 차이는 이번 검색에서 제외하고 첫 세 유종만 받습니다.

### 빈 응답과 이용 조건

네 경로를 무효 시험 키로 확인했습니다. **오피넷 세 경로 모두 HTTP 200의 `RESULT.OIL: []`**을 반환해 키 오류와 실제 결과 부재를 구분할 수 없었습니다. 따라서 빈 목록은 `PROVIDER_EMPTY_UNVERIFIED`·**결과 확인 필요(`needs_review`)**로 중단합니다. 성공/자료 없음/인증 성공으로 표시하지 않고 실제 계정 성공 증거도 만들지 않습니다. 본인 신청·키·조회 조건을 확인한 뒤 재조회하세요. 무효 키를 새로 발급해 해결된 것으로 추정하지 않습니다.

일반 API는 공식 안내의 **하루 300회**, 확대 사용·프리미엄은 별도 제휴 조건을 확인합니다. 자료 재표시에는 출처·원문 내용을 보존하며 상업적 활용은 석유공사의 이용 조건을 확인해야 합니다. 키는 서버의 기존 암호화 저장소에 보관하고 미리보기·모델 결과에 전달하지 않습니다.

## 검증과 남은 단계

단위/엔진/HTTP·모바일 크기 화면·Linux·실제 HTTPS 오류는 [검증 기록](VALIDATION.md)에서 구분합니다. 실제 사용자 키 정상 응답·최신 지역·문서 차이·페이지/가격/상태 경계·한도·실제 휴대폰/GCP는 추가 확인해야 합니다. 시험 산출물과 무효 키 응답은 사용자 데이터베이스로 옮기지 않습니다.

두 서비스 모두 고정 HTTPS·30초·2MB·UTF-8 검사·취소·키/오류 비노출을 적용하고 자동 재시도하지 않습니다. 후속 기능은 충전소 시군구 탐색·근처/거리순·차량별 필터와 오피넷 KATEC 변환·반경 검색입니다. [작업 체크리스트](../TODO.md)
