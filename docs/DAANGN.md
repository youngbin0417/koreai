# 당근 첫 조회 기능 정의

확인일: **2026-10-15**. 첫 범위는 **검색어·동네로 공개 중고 물품 후보 찾기**입니다. 제안 규격과 비활성 행동을 등록했으며 자동 검색·채팅·판매글 작성·동네 인증은 제공하지 않습니다.

## 첫 행동과 제안 규격

- 행동 ID: `daangn.items.search`
- 효과·방식: 읽기·`partnership`, `implemented: false`, `enabled: false`
- 상태: 기능 정의 완료·공급자 확인 대기. 입력·출력은 KoreAI 제안이며 공급자 API 명세가 아님.
- 자격정보: 소비자 인증 방식 미확인. 임의의 키 유형·토큰·쿠키·위치 증명을 받지 않음.

```json
{"query":"자전거","region":"서울특별시 강남구 역삼동","limit":5}
```

`query`는 1~100자 검색어, `region`은 **필수** 1~80자 동네 이름입니다. 동명 동네를 구분할 수 있게 시·구를 함께 입력합니다. 동네 이름을 인증 완료나 현재 GPS 위치로 간주하지 않습니다. `limit`은 기본 5·최대 20인 KoreAI 제안 상한이며 공급자 한도는 확인 대기입니다. 임의 URL·키·쿠키·좌표·채팅 식별자 등의 추가 필드는 거절합니다.

제안 결과는 `status`, `query`, `region`, `items[]`, `retrievedAt`, `providerUpdatedAt`입니다. 물품별 필드는 다음과 같습니다.

| 필드 | 제안 의미 |
|---|---|
| `providerId`, `title`, `neighborhoodText` | 제공된 식별자·제목·동네 표기. 식별자·동네 미제공은 `null` |
| `price.kind` | `amount`, `free`, `negotiable`, `unknown` |
| `price.amountKrw`, `price.text` | 명시된 원 단위 정수와 표시 원문. 미제공·가격 제안은 금액 `null`, 명시적인 나눔은 `free`·0 |
| `transactionStatus`, `transactionStatusText` | 표시된 `for_sale`, `reserved`, `sold`, `unknown` 상태와 원문. 실제 구매 가능 보증이 아님 |
| `sourceUrl` | 공식 중고거래 상세 HTTPS 링크. 인증정보·임의 도메인·쿼리 불허 |

가격이 없다고 0원·나눔으로 바꾸지 않습니다. 예약중·판매완료를 판매중으로 바꾸지 않으며, 목록 결과가 있다는 `status: available`은 물품 구매 가능 상태를 뜻하지 않습니다. 로그인·동네 인증 필요·접근 거절·통신 실패는 검색 결과 없음과 구분해야 합니다. 판매자 프로필·전화번호·상세 위치·개인 채팅·거래내역은 첫 결과 범위에 넣지 않습니다.

## 현재 사용하는 방법

1. **기본 서비스 연결 → 당근마켓**에서 첫 조회 규격·계정 조건을 확인합니다.
2. **공개 중고거래 목록 직접 확인** 경로를 선택하고 준비 상태를 저장합니다.
3. **서비스 열기** 또는 **중고거래 목록 직접 확인** 링크에서 사용자가 동네·검색어를 직접 선택합니다.

준비 API는 `PUT /api/connections/daangn`에 `{"routeId":"items"}`를 보냅니다. 기존 `daangn.connection.open`은 입력 `{}`로 선택한 고정 URL만 반환하며 검색어·동네를 전송하거나 목록을 읽지 않습니다. 조회 초안의 실행은 관리자와 에이전트 모두 409 `NOT_IMPLEMENTED`로 거절합니다. 준비 저장으로 활성화되지 않습니다.

`daangn.connection.status`와 허용된 `GET /api/connections`의 `firstRead`에 제안 JSON Schema·예시·계정 조건·결과 확인·다음 조사가 포함됩니다. `automaticActions: 0`, `accountVerified: false`를 유지하고 링크 안내·제안 규격으로 실제 지원 수를 늘리지 않습니다.

## 광고 MCP의 별도 후속 연동

공식 가이드가 안내하는 서버는 `https://ads-mcp.kr.karrotmarket.com/mcp`입니다. 광고 계정의 기존 권한을 따르며 소비자 거래·채팅·동네 인증 권한을 추가하지 않습니다. 가이드 확인 시 계정당 초당 2회 한도이며 변경 가능성이 있습니다. 클라이언트 지원에 상충하는 설명이 있어 실제 호환성 검증이 필요합니다.

`ads-mcp-guide` 경로는 **가이드 링크**를 제공합니다. KoreAI의 [공통 MCP OAuth 로그인·갱신](MCP_OAUTH.md)은 구현·시험 서버 검증을 완료했습니다. 당근 광고의 실제 클라이언트 등록·로그인·도구 목록·계정별 범위·취소/한도·호환성은 사용자 광고 계정으로 별도 검증해야 합니다. 서버 주소 등록만으로 연결 완료라고 표시하지 않으며, 상위 도구의 읽기 힌트로 승인을 생략하지 않습니다.

## 공급자 확인과 활성화 조건

소비자 검색 API/제휴 또는 전용 브라우저 조회의 허용 여부, 동네 선택·인증 범위, 결과 필드·상태·페이지/한도, 보관·LLM 전달 조건을 먼저 확인합니다. 아래는 미발송 문의 질문 초안입니다.

1. 일반 소비자의 공개 중고 물품 검색을 외부 에이전트에 제공하는 공식 방식이 있는가?
2. 검색 동네와 인증 동네는 어떻게 구분하며 동명 동네·검색 반경은 어떻게 지정하는가?
3. 제목·가격 원문·거래 상태·공식 링크의 제공 범위, 갱신·캐시·삭제·호출 한도 조건은 무엇인가?
4. API가 없다면 사용자 소유 전용 브라우저의 자동 조회가 허용되는가?
5. 광고 MCP는 별도 사업자 범위로 연결할 때 어떤 OAuth·계정·도구 권한 조건을 따라야 하는가?
