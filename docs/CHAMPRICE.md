# 참가격 생필품 조사 가격 조회

확인일: **2026-10-21**. 한국소비자원이 제공한 **2026년 8월·9월 조사 파일**을 선택해 키 없이 조회합니다. 기본은 9월이며, 검증된 다운로드 파일을 재사용합니다. [공식 데이터·이용 조건](https://www.data.go.kr/data/15083256/fileData.do)

## 바로 사용하기

**확장 계획 → 참가격 → 조회 기능 열기 → 참가격 조사월 선택 → 예시 입력 불러오기 → 실행 요청**을 누릅니다. 계정·API 키 등록은 필요하지 않습니다. 요청 구조 미리보기는 다운로드를 실행하지 않습니다. 월을 바꾸면 다른 월의 조사일 조건을 지우고 화면에 안내합니다. 예시 입력은 선택한 월을 유지합니다.

DeepSeek 새 대화의 허용 기능에서 **참가격 생필품 조사 가격 찾기**를 선택하거나 HTTP/MCP 클라이언트에 `champrice.prices.search`를 허용할 수 있습니다. 검색 조건은 로컬 서버에서 적용하고 공급자에게 전송하지 않습니다.

```json
{
  "month": "2026-08",
  "productName": "우유",
  "surveyDate": "2026-08-28",
  "page": 1,
  "limit": 10
}
```

| 입력 | 범위 |
|---|---|
| `month` | 검토된 `2026-08`, `2026-09`. 생략하면 `2026-09` |
| `productName` | 필수 상품명 검색어, 1~100자·제어문자 제외·앞뒤 공백 제거 |
| `match` | `contains`(기본 부분 일치), `exact`(상품명 전체 일치) |
| `manufacturer` | 선택, 제조사 전체 일치 |
| `storeQuery` | 선택, 판매업소명 부분 일치. 자유 지역명 필터가 아님 |
| `surveyDate` | 선택, 선택한 월 안의 실제 날짜 형식. 다른 월이면 실행 전 거절. 생략하면 그 파일의 조사일 전체 검색 |
| `page` / `limit` | 1~10,000 / 1~50, 기본 1 / 10 |

문자 검색은 NFC·대소문자 정규화 후 적용합니다. 상품명 정확 일치도 동일 상품·용량의 인증이 아닙니다. 제공 파일에는 비교에 쓸 상품/업소 ID·규격별 단위 필드가 없으므로 원문을 확인해야 합니다.

업데이트 전의 9월 요청도 같은 멱등키로 재요청하면 기존 작업을 반환합니다. 새로운 월·조건으로 조회할 때는 새 멱등키를 사용합니다.

## 결과 읽기

- `prices`: 상품명·제조사·판매업소·조사일 원문, 원 단위 `priceKrw`와 `priceRaw`를 반환합니다. 선행 0과 금액 `0`은 보존합니다.
- `sale`, `onePlusOne`: `Y`는 `true`, `N`은 `false`, 미집계 빈 값은 `null`입니다. 빈 값을 할인 없음으로 바꾸거나 두 할인 조건을 합산하지 않습니다.
- `currentPriceKrw`, `inStock`, `quantity`, `unitPriceKrw`는 `null`, `productIdentityVerified`는 `false`입니다. 현재 결제가·재고·단위 가격·가격 순위는 판정하지 않습니다.
- `sourceRow`는 이 파일 안의 데이터 행 참조입니다. 공급자 상품 ID가 아니며 동일한 원문 행도 임의로 병합하지 않습니다.
- `snapshot`에 선택한 조사월·발행일·파일에서 확인한 조사일·SHA-256·인코딩을 표시합니다. `retrievedAt`은 파일의 다운로드·검증 완료 시각, `queriedAt`은 이번 검색 시각입니다. 캐시 재사용으로 다운로드 시각을 갱신하지 않습니다.
- `cache.status`는 첫 다운로드 `downloaded`, 다른 요청과 다운로드 공유 `shared`, 저장 파일 재사용 `hit`입니다. `cache.downloadedAt`, `expiresAt`, `byteLength`, `sha256`도 반환합니다.
- 전체 파일 검증 후 `totalSourceRows`, `totalMatches`, 페이지를 반환합니다. `no_data`는 검색 0건, `empty_page`는 일치 결과 이후의 페이지입니다. `pageLimitReached`가 참이면 입력 가능한 마지막 페이지 이후에도 결과가 남아 있습니다.

결과 순서는 원본 파일 순서입니다. 여러 상품/용량·조사일을 섞어 최저가를 표시하지 않습니다. 웹·LLM에 전달하는 결과에도 조사 시점과 출처를 유지합니다.

## 데이터와 운영 범위

공식 현재/과거 자료에서 확인한 두 첨부파일의 CSV 상세 1을 사용합니다. 로그인·쿠키·키 없이 HTTPS GET 한 번으로 받으며 리다이렉트는 거절합니다. 검토하지 않은 월·임의 URL은 입력받지 않습니다.

| 조사월 | 공식 첨부파일 | 공개일 | 실제 행 수·크기 | 확인한 조사일 |
|---|---|---|---|---|
| 2026-08 | `FILE_000000007654112` | 2026-09-07 | 246,543건·17,764,710바이트 | 8/7·8/28 |
| 2026-09 | `FILE_000000007707356` | 2026-10-02 | 235,632건·16,945,426바이트 | 9/11·9/25 |

8월 출처는 공식 페이지의 공개 과거 자료 목록과 [상세 정보](https://www.data.go.kr/tcs/dss/selectDpkDetailInfo.do?publicDataDetailPk=uddi%3Ad52c60ca-9b2f-4984-a6e0-a68a2cdd12d2&publicDataHistSn=1)입니다. 검토 목록은 [`champrice-snapshots.ts`](../src/research/champrice-snapshots.ts)에 있습니다.

두 실제 파일은 **CP949**였습니다. 메타데이터의 영문 항목명과 달리 CSV 헤더는 `상품명,조사일,판매가격,판매업소,제조사,세일여부,원플러스원`입니다. HTTP는 UTF-8로 표시했지만 실제 바이트는 CP949였으므로 UTF-8/BOM 확인 후 CP949 왕복 검증으로 인코딩을 구분합니다.

공식 제공 주기는 월간이고 이용허락범위는 제한 없음으로 표시돼 있습니다. 이 구현은 검토한 두 달의 목록에서만 선택하며 새 월을 자동 등록하지 않습니다. 새 파일은 주소·헤더·시점·형식·이용 조건을 확인한 뒤 별도 갱신해야 합니다. 목록/파서 변경 시 캐시 식별자도 바뀌어 이전 파일을 다른 자료로 재사용하지 않습니다.

파일이 없거나 만료/손상된 경우 약 17~18MB를 다운로드합니다. 60초·32MB·300,000행·필드 2,000자 상한을 적용하고 모든 행을 검증한 뒤 캐시에 넣습니다. 결과 페이지 행만 보관해 전체 레코드 배열을 만들지 않습니다. 자료 기간/형식 변경·잘못된 가격/할인·HTML·잘린 본문·상한 초과는 중단하며 자동 재시도하지 않습니다. 빈 원본은 검색 0건으로 처리하지 않고 결과 확인 필요 상태를 남깁니다.

## 캐시 운영

- 저장 위치는 데이터 폴더의 `champrice-cache/`입니다. 공개 CSV와 크기·SHA-256·다운로드/만료 시각·제공 갱신 헤더를 저장하며 사용자 검색 조건·키·쿠키는 넣지 않습니다. 모의 시험은 별도 `champrice-cache-mock/`을 사용합니다.
- 기본 사용기한은 다운로드·검증 완료 후 **7일**, 전체 저장 상한은 **64,000,000바이트·완료 파일 3개**입니다. 메타데이터와 쓰기 중 임시 공간도 상한에 반영합니다. 공간이 부족하면 먼저 다운로드한 파일부터 폐기합니다. 읽기만으로 만료일을 연장하지 않습니다.
- 서버 시작/조회 시 만료·잘린 메타데이터·고아 본문·중단된 임시 파일을 정리합니다. 재사용할 때 파일 종류·크기·SHA-256을 검사하고 손상 파일은 폐기 후 새로 다운로드합니다.
- 같은 자료의 동시 요청은 한 다운로드를 공유합니다. 각 작업의 권한을 전달 직전에 확인하며 한 작업의 취소는 다른 대기자를 취소하지 않습니다. 대기자가 모두 취소하면 진행 중 다운로드를 중단하고 미완료 파일을 게시하지 않습니다.
- 파일과 메타데이터를 임시 파일에서 동기화한 뒤 원자적으로 게시합니다. Linux 디렉터리/파일 권한은 `0700`/`0600`이며 링크 경로·외부 대상은 따라가지 않습니다. 엔진은 데이터 폴더를 한 프로세스가 소유합니다.
