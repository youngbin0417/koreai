# 참가격 생필품 조사 가격 조회

확인일: **2026-10-21**. 한국소비자원이 공공데이터포털에 제공한 **2026년 9월 조사 파일**을 키 없이 조회합니다. [공식 데이터·이용 조건](https://www.data.go.kr/data/15083256/fileData.do)

## 바로 사용하기

**확장 계획 → 참가격 → 조회 기능 열기 → 예시 입력 불러오기 → 실행 요청**을 누릅니다. 계정·API 키 등록은 필요하지 않습니다. 요청 구조 미리보기는 다운로드를 실행하지 않습니다.

DeepSeek 새 대화의 허용 기능에서 **참가격 생필품 조사 가격 찾기**를 선택하거나 HTTP/MCP 클라이언트에 `champrice.prices.search`를 허용할 수 있습니다. 검색 조건은 로컬 서버에서 적용하고 공급자에게 전송하지 않습니다.

```json
{
  "productName": "우유",
  "surveyDate": "2026-09-25",
  "page": 1,
  "limit": 10
}
```

| 입력 | 범위 |
|---|---|
| `productName` | 필수 상품명 검색어, 1~100자·제어문자 제외·앞뒤 공백 제거 |
| `match` | `contains`(기본 부분 일치), `exact`(상품명 전체 일치) |
| `manufacturer` | 선택, 제조사 전체 일치 |
| `storeQuery` | 선택, 판매업소명 부분 일치. 자유 지역명 필터가 아님 |
| `surveyDate` | 선택, `2026-09` 안의 실제 날짜 형식. 생략하면 파일의 조사일 전체 검색 |
| `page` / `limit` | 1~10,000 / 1~50, 기본 1 / 10 |

문자 검색은 NFC·대소문자 정규화 후 적용합니다. 상품명 정확 일치도 동일 상품·용량의 인증이 아닙니다. 제공 파일에는 비교에 쓸 상품/업소 ID·규격별 단위 필드가 없으므로 원문을 확인해야 합니다.

## 결과 읽기

- `prices`: 상품명·제조사·판매업소·조사일 원문, 원 단위 `priceKrw`와 `priceRaw`를 반환합니다. 선행 0과 금액 `0`은 보존합니다.
- `sale`, `onePlusOne`: `Y`는 `true`, `N`은 `false`, 미집계 빈 값은 `null`입니다. 빈 값을 할인 없음으로 바꾸거나 두 할인 조건을 합산하지 않습니다.
- `currentPriceKrw`, `inStock`, `quantity`, `unitPriceKrw`는 `null`, `productIdentityVerified`는 `false`입니다. 현재 결제가·재고·단위 가격·가격 순위는 판정하지 않습니다.
- `sourceRow`는 이 파일 안의 데이터 행 참조입니다. 공급자 상품 ID가 아니며 동일한 원문 행도 임의로 병합하지 않습니다.
- `snapshot`에 고정 조사월·발행일·파일에서 확인한 조사일·SHA-256·인코딩을, `retrievedAt`에 다운로드한 시각을 표시합니다. 다운로드 시각을 가격 조사 시각으로 사용하지 않습니다.
- 전체 파일 검증 후 `totalSourceRows`, `totalMatches`, 페이지를 반환합니다. `no_data`는 검색 0건, `empty_page`는 일치 결과 이후의 페이지입니다. `pageLimitReached`가 참이면 입력 가능한 마지막 페이지 이후에도 결과가 남아 있습니다.

결과 순서는 원본 파일 순서입니다. 여러 상품/용량·조사일을 섞어 최저가를 표시하지 않습니다. 웹·LLM에 전달하는 결과에도 조사 시점과 출처를 유지합니다.

## 데이터와 운영 범위

공식 페이지의 `DataDownload.contentUrl`에서 확인한 고정 첨부파일 `FILE_000000007707356`·상세 1을 사용합니다. 로그인·쿠키·키 없이 HTTPS GET 한 번으로 받으며 리다이렉트는 거절합니다. 다른 월·임의 URL은 입력받지 않습니다.

실제 파일은 **CP949·16,945,426바이트·235,632건**, 조사일은 **2026-09-11 / 2026-09-25**였습니다. 메타데이터의 영문 항목명과 달리 CSV 헤더는 `상품명,조사일,판매가격,판매업소,제조사,세일여부,원플러스원`입니다. HTTP는 UTF-8로 표시했지만 실제 바이트는 CP949였으므로 UTF-8/BOM 확인 후 CP949 왕복 검증으로 인코딩을 구분합니다.

공식 제공 주기는 월간이고 해당 파일의 등록/수정일은 2026-10-02입니다. 이용허락범위는 제한 없음으로 표시돼 있습니다. 이 구현은 검토한 9월 파일을 고정하며 새 월을 자동 선택하지 않습니다. 다음 등록 예정일은 새 자료 공개를 보장하는 날짜가 아닙니다. 새 파일은 주소·헤더·시점·형식을 확인한 뒤 별도 갱신해야 합니다.

매 실행은 전체 파일 약 17MB를 다운로드합니다. 다른 멱등키로 새 검색을 하면 다시 받으며 캐시·증분 갱신은 후속입니다. 60초·32MB·300,000행·필드 2,000자 상한을 적용하고 모든 행을 확인합니다. 결과 페이지 수만큼만 행을 보관해 전체 레코드 배열을 만들지 않습니다. 자료 기간/형식 변경·잘못된 가격/할인·HTML·잘린 본문·상한 초과는 중단하며 자동 재시도하지 않습니다. 빈 원본은 검색 0건으로 처리하지 않고 결과 확인 필요 상태를 남깁니다.
