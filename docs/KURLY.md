# 마켓컬리 첫 조회 기능 정의

확인일: **2026-10-15**. 첫 범위는 **검색어로 공개 상품 후보 찾기**입니다. 제안 규격·비활성 행동·관리 화면을 추가했습니다. 소비자 상품 API의 요청·인증 규격과 자동 접근 허용 범위는 확인 대기입니다.

## 공식 근거와 연결 범위

| 근거 | 확인한 내용 | KoreAI 적용 |
|---|---|---|
| [공식 상품 서비스](https://www.kurly.com/main) | 기존 루트 주소가 `/main`으로 이동. 공개 상품 카드에 옵션·시작가·회원/쿠폰 조건 표시 | 사용자 직접 확인용 고정 링크. 상품 검색 동작·자동 접근 허용을 검증한 것은 아님 |
| [공식 상품 상세 예시](https://www.kurly.com/goods/5031442) | 옵션 선택·조건부 가격·배송 안내와 옵션 미선택 총액 표시를 확인 | 공개 페이지 구조 참고만 수행. 상품명·가격·재고를 코드에 고정하지 않음 |
| [KLS 서비스 소개](https://developers.kurly.com/docs/intro/) | 계약 화주사의 물류/배송대행과 배송 추적 연동. 물류 상품·입고·재고·출고 등 제공 | 소비자 상품 카탈로그·구매내역과 다른 범위로 기록 |
| [KLS 인증](https://developers.kurly.com/docs/auth/) | 접속 IP 등록, `secretKey`·`clientId` 발급, Access Token·Bearer 인증 안내 | 물류 인증 안내 링크 제공. 실제 발급·인증·호출은 미수행 |

KLS 문서의 ‘상품·재고·주문 조회’를 소비자 상품 검색·구매 가능 수량·개인 구매내역으로 해석하지 않습니다. 소비자 API가 없다고 단정하지 않으며 공급자 제공 경로·이용 조건·자동 접근 허용을 확인한 뒤 실행기를 구현합니다. 현재 KLS 어댑터도 구현하지 않았습니다.

## 첫 행동과 제안 규격

- 행동 ID: `kurly.products.search`
- 효과·방식: 읽기·`partnership`, `implemented: false`, `enabled: false`
- 상태: 정의 완료·공급자 확인 대기. 아래 입력·결과는 **KoreAI 제안**이며 공급자 API 명세가 아님.
- 자격정보: 소비자 인증 방식 미확인. KLS 키·쿠키·개인 배송지 입력을 받지 않음.

```json
{"query":"우유","limit":5}
```

`query`는 공백 제거 후 1~100자, `limit`은 기본 5·1~20인 제안 상한입니다. 공급자의 검색 필드·호출 한도는 확인 대기입니다. 임의 URL·KLS 자격정보·회원 여부·배송지 등의 추가 필드는 거절합니다.

제안 결과는 `status`, `query`, `products[]`, `retrievedAt`, `providerUpdatedAt`입니다. 상품별 필드는 다음과 같습니다.

| 필드 | 제안 의미 |
|---|---|
| `providerId`, `title`, `sourceUrl` | 제공된 식별자·이름·공식 상품 상세 HTTPS 링크. 식별자 미제공은 `null` |
| `optionText` | 용량·구성·택일 등의 표시 원문. 옵션 자동 선택 없음 |
| `price.kind` | `listed`: 화면 표시 금액, `from`: 옵션별 시작가, `unknown`: 금액 미확인 |
| `price.amountKrw`, `price.text` | 원 단위 안전한 양의 정수와 원문. 미확인 금액은 `null` |
| `price.conditionsText` | 회원·쿠폰 등 표시된 가격 조건 원문. 조건 적용 검증은 하지 않음 |
| `availabilityText` | 품절 등 명시된 안내 원문. 미제공은 `null` |
| `deliveryText`, `deliveryEligibility` | 배송 안내 원문과 고정값 `not_verified`. 주소별 배송·도착 보장 없음 |

화면 표시 가격도 결제 확정가가 아닙니다. 옵션을 선택하지 않아 표시되는 **총 상품금액 0원**을 무료 상품으로 바꾸지 않으며, 미확인 가격은 `unknown`·`null`로 남깁니다. 첫 규격은 0원 상품의 정규화를 지원하지 않습니다. 회원·쿠폰 혜택을 자동 적용하거나 할인율로 가격을 계산하지 않습니다.

`status: available`은 검색 데이터가 있다는 의미입니다. 품절 상품도 결과에 포함될 수 있으며 담기 버튼만으로 재고·구매 가능 여부를 판정하지 않습니다. 배송 문구를 사용자의 주소에 대한 배송 가능·도착 예정일로 확정하지 않습니다. 로그인 필요·접근 거절·통신 오류는 빈 결과와 구분해야 합니다.

결과 링크는 `https://www.kurly.com/goods/<숫자 ID>`의 제안 형식만 허용합니다. 인증정보·다른 도메인·쿼리·프래그먼트는 거절합니다. 주문/구매내역·주소·결제·장바구니는 첫 조회 결과 범위에서 제외했습니다. 현재 상품 수집·가격 파싱·결과 정규화 실행은 제공하지 않습니다.

## 현재 사용하는 방법

1. **기본 서비스 연결 → 마켓컬리**에서 첫 조회 규격과 확인 대기 항목을 봅니다.
2. **공식 상품 직접 확인** 경로를 선택하고 **연결 준비 저장**을 누릅니다.
3. **서비스 열기**에서 공식 홈으로 이동해 사용자가 상품을 직접 찾습니다.

준비 API는 `PUT /api/connections/kurly`에 `{"routeId":"products"}`를 보냅니다. 기존 `consumer`·`logistics` 경로를 유지하며 `logistics-auth`는 물류 인증 안내 링크입니다. 어느 경로도 키 발급·물류 인증·소비자 검색을 실행하지 않습니다.

`kurly.connection.open`은 입력 `{}`로 선택한 고정 URL만 반환합니다. 검색어를 외부로 전송하거나 페이지를 읽지 않습니다. `kurly.connection.status`와 허용된 `GET /api/connections`의 `firstRead`에서 제안 JSON Schema·예시·계정 조건·결과 확인·다음 조사 항목을 볼 수 있습니다.

상품 검색 초안 실행은 관리자와 허용된 에이전트 모두 409 `NOT_IMPLEMENTED`로 거절하며 작업을 생성하지 않습니다. 준비 저장으로 활성화되지 않습니다. `automaticActions: 0`·`accountVerified: false`를 유지하고 링크 안내·정의 완료를 실제 지원 실적으로 집계하지 않습니다.
