# 서울 따릉이 대여소 조회

확인: **2026-10-17**. 행동 `seoul-bike.stations`, 계정 `seoul-bike-api`. 서울시 공개 대여정보의 요청 구간에서 대여소 ID·이름·잔여 자전거·거치대·거치율·좌표를 반환합니다. 이용권 결제·대여·잠금 해제는 포함하지 않습니다.

## 연결 조건과 Linux 설정

공식 [데이터셋](https://data.seoul.go.kr/dataList/OA-15493/A/1/datasetView.do)과 [Open API 이용 안내](https://data.seoul.go.kr/together/guide/useGuide.do)를 확인했습니다. 일반 인증키를 본인 계정으로 발급받아 사용하세요. 따릉이 앱 로그인과 공공데이터포털 키는 별개입니다. 출처는 결과에도 표시합니다.

공식 안내의 접속 주소는 `http://openapi.seoul.go.kr:8088`입니다. 공개 `sample` 키로 JSON 5건을 실제 확인했습니다. 같은 호스트의 HTTPS 8088은 TLS 오류, HTTPS 8089·443은 이 환경에서 시간 초과였습니다. 공식 HTTPS 지원 여부는 계속 확인할 항목입니다.

**기본 설정은 HTTP 전송 차단입니다.** 허용 시 서버→서울 데이터 API 구간에서 키와 응답이 암호화되지 않으며 중간에서 읽거나 변조할 수 있습니다. 휴대폰→KoreAI의 Tailscale HTTPS는 이 구간을 보호하지 않습니다. 운영자가 이 조건으로 사용하기로 결정한 경우에만 설정하세요. 키는 전용으로 발급하고 다른 서비스의 비밀을 재사용하지 마세요.

직접 실행:

```bash
KOREAI_ALLOW_SEOUL_BIKE_HTTP=1 npm start
```

GCP 설치 스크립트의 사용자 systemd 서비스를 사용한다면 `~/.config/koreai/server.env`에 다음 행을 추가하고 재시작합니다. 기존 `KOREAI_PUBLIC_URL` 행은 유지하세요.

```ini
KOREAI_ALLOW_SEOUL_BIKE_HTTP=1
```

```bash
systemctl --user restart koreai
```

변수를 제거하거나 `0`으로 바꾸고 재시작하면 다시 차단됩니다. 임의의 참 문자열은 허용하지 않으며 정확히 `1`만 인정합니다. 에이전트·HTTP 입력·페이지 내용은 이 설정을 바꿀 수 없습니다. 설정 변경 후 이전 실패 작업은 다시 실행되지 않으므로 새 요청을 만드세요. 기본 일반 Linux 서비스에는 필요한 경우 systemd `Environment=` 재정의를 적용합니다.

## 관리 화면에서 실행

1. **연결 계정 → 계정 연결 → 서울 따릉이**에서 일반 인증키를 입력하고 **서울 따릉이 대여소 잔여 자전거 조회**를 허용합니다. 키는 기존 로컬 암호화 저장소에 보관합니다.
2. **확장 계획 → 서울 따릉이 → 조회 기능 열기 → 예시 입력 불러오기**를 선택합니다. 운영자 설정이 꺼져 있으면 화면에 차단 이유가 표시되고 실행 버튼이 비활성화됩니다.
3. 구간과 필터를 확인하고 실행합니다. 미리보기에는 `{apiKey}` 자리표시자와 HTTP 전송 조건만 나오며 키 조회·공급자 호출은 없습니다.

```json
{"start":1,"end":100,"query":"망원"}
```

| 입력 | 의미 |
|---|---|
| `start` / `end` | 1부터 시작하는 포함 구간. 기본 1~100, 한 번에 최대 1,000건. 앱의 상한은 위치 1,000,000 |
| `query` | 선택 사항. 해당 구간 대여소 이름의 부분 일치, 최대 80자 |
| `stationId` | 선택 사항. 해당 구간에서 `ST-5` 같은 공급자 ID의 정확한 일치 |

`query`·`stationId`는 **받아온 구간 안에서만** 필터링합니다. `103.` 같은 이름 앞 번호와 `ST-5`는 다른 값입니다. 도시 전체 이름 검색이나 거리순 검색이 아닙니다. 구간을 자동으로 반복 호출하지 않습니다. 다음 구간은 사용자가 필요에 따라 요청합니다.

HTTP·MCP에서도 같은 행동·입력을 사용합니다. 에이전트에 행동과 해당 계정을 모두 허용해야 합니다. HTTP 전송 설정이 꺼진 상태에서 직접 호출하면 공급자 요청 전 `TRANSPORT_DISABLED`로 실패합니다.

## 결과와 오류

- `stations`: `stationId`, `name`, `rackCount`, `availableBikes`, `parkingRatioPercent`, `latitude`, `longitude`. 자전거가 거치대 수를 초과하거나 거치율이 100을 넘는 응답도 유효합니다. 반납 가능 수를 뺄셈으로 계산하지 않습니다.
- `retrievedAt`: KoreAI가 응답을 조회한 시각. `providerUpdatedAt: null`: API가 관측 시각을 제공하지 않았다는 뜻입니다. 최신 관측 시각을 임의로 만들지 않습니다.
- `providerReturnedCount`는 필터 전 행 수, `returnedCount`는 필터 후 행 수입니다. `providerReportedCount`는 원본 `list_total_count`이며 서울 전체 대여소 수로 해석하지 않습니다.
- `pagination.totalStations`·`hasMore`는 미확인으로 `null`입니다. 구간이 꽉 찼을 때만 `suggestedNextRange`를 제안하며 다음 페이지의 존재를 보장하지 않습니다.
- 빈 구간은 `empty_provider_range`, 구간 안 필터 불일치는 `no_match_in_range`입니다. 도시 전체 결과 없음이나 실제 대여 불가로 해석하지 않습니다.
- 무효 키 `INFO-100`·HTTP 401/403은 `awaiting_auth`로 보존합니다. 실제 무효 시험 키로 JSON 요청에도 XML `INFO-100`이 반환됨을 확인해 두 오류 형식을 처리합니다. XML 외부 엔티티/DOCTYPE와 정상 데이터의 XML 대체는 거절합니다. 키를 수정한 뒤 수동 재개하세요. `sample` 키는 실사용 계정에서 거절하며 샘플로 자동 대체하지 않습니다.
- 고정 도메인·8088 포트·JSON 경로만 호출하고 리디렉션은 거절합니다. 응답 2MB·30초·취소·중복 ID·좌표/숫자·구간 초과를 검사합니다. 공급자의 오류 원문과 키가 든 URL은 결과/일반 오류에 전달하지 않습니다.

## 검증과 다음 작업

모의 응답으로 실행기·HTTP 권한·멱등성·인증 대기와 실제 Edge의 390px 화면 흐름을 검증합니다. 공식 공개 샘플의 접속 확인은 본인 키 검증·배포 지원 실적과 구분합니다. 실제 키 호출·운영 한도·지역/구간별 제공 범위는 아직 검증하지 않았으며 지원 집계에 포함하지 않습니다. [검증 기록](VALIDATION.md#2026-10-17-서울-따릉이-조회-검증)

후속: 본인 키의 정상/빈 응답·한도 확인, 공식 HTTPS 제공 여부 재확인, 대여소 전체 탐색·위치 기반 찾기의 요청/캐시 정책 정의. 잔여 수가 실제 도착 시점의 대여를 보장하지는 않습니다.
