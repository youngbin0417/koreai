# 추가 요청 앱·생활 서비스 목록

등록: **2026-10-16**. 요청과 대안 서비스 **36개**를 기존 항목과 ID로 병합했습니다. 전체 조사 카탈로그는 **99개**, 확장 후보는 **58개**입니다. 야놀자는 기존 `nol` 항목으로 통합하고 YES24 도서는 티켓과 구분합니다.

관리 화면의 **확장 계획 → 추가 요청 앱만 보기**에서 검색하고 **첫 연결 초안**을 펼치세요. 한국어·영문 별칭도 검색합니다. **2026-10-17 따릉이 조회 실행기와 계정 화면을 추가**했습니다. [연결 조건](SEOUL_BIKE.md)에 따라 운영자가 HTTP 전송을 허용해야 실행되며 본인 키 검증은 남아 있습니다. 나머지 항목은 조사·설계이고 공식 API 상세 미확인 서비스는 미조사 상태를 유지합니다. 모의·샘플 검증은 지원 실적으로 집계하지 않습니다.

## 구현 순서 제안

1. **따릉이 → 알라딘 → 치지직:** 따릉이 실행기 구현 완료·본인 키 검증 대기. 다음은 알라딘의 TTB 키·약관·표시 조건을 확인하고 도서 조회를 구현.
2. **동물병원 찾기:** 공공 인허가 데이터의 파일 규격·좌표계·영업상태·갱신일을 검증. 진료비 공개는 지역 통계로 별도 취급.
3. **매장·채용·상품·여행:** 소비자 조회 API/제휴와 자동 접근 허용을 확인한 서비스부터 첫 조회 행동 구현.
4. **개인 세금·공과금·통신비:** 공개 안내와 개인 고지·청구 조회를 나누고 공급자별 본인 인증·동의·최소 필드·보관 조건을 먼저 확정. 예약·지원·신고·납부·후원·주문은 후속 승인 단계.
