# HIRA 병원정보 검색

확인일 **2026-10-19**. 심평원 병원정보서비스의 현재 공식 Swagger에 있는 `hospInfoServicev2/getHospBasisList`를 구현했습니다. 신고 기준의 기관 정보를 조회합니다. 실제 HTTPS에서 무효 시험 키의 403·게이트웨이 코드 30을 확인했으며 정상·빈 결과는 모의 XML로 검증했습니다. 유효한 본인 키의 정상 응답 검증은 남아 있습니다.

## 계정 연결

1. [공공데이터포털 병원정보서비스](https://www.data.go.kr/data/15001698/openapi.do)를 활용 신청하고 승인 상태를 확인합니다.
2. KoreAI **연결 계정 → HIRA 병원정보**에 일반 인증키 **Decoding** 값을 `serviceKey`로 등록하고 **HIRA 병원정보 검색**을 허용합니다. 호출할 대화·에이전트에도 해당 계정과 행동을 허용합니다.
3. **확장 계획 → 건강보험심사평가원 → 조회 기능 열기**에서 예시 입력·미리보기를 확인한 뒤 실행합니다.

공공데이터포털 키를 쓰더라도 서비스별 활용신청이 필요합니다. 기존 E-Gen 계정의 승인만으로 HIRA를 호출하지 않습니다. 미리보기는 키 조회·외부 호출·작업 생성 없이 동작하며, 실행 시에만 암호화 저장소의 키를 공급자의 `ServiceKey`에 주입합니다. 키를 사전 URL 인코딩하거나 모델 입력에 넣지 않습니다.

Linux에서도 서버가 직접 HTTPS로 호출합니다. GUI 브라우저·심평원 사용자 로그인은 필요하지 않습니다. 휴대폰에서는 기존 HTTPS 관리 주소에 접속합니다.

## 행동과 입력

행동 ID: **`hira.hospitals.search`**

```json
{"name":"서울의료원","provinceCode":"110000","districtCode":"110019","page":1,"limit":10}
```

```json
{"provinceCode":"110000","districtCode":"110001","institutionTypeCode":"31","departmentCode":"01","limit":10}
```

| KoreAI 입력 | 공급자 필드 | 규격·예시 |
|---|---|---|
| `name` | `yadmNm` | 병원명, 최대 150자 |
| `provinceCode` | `sidoCd` | HIRA 시도코드 문자열. 서울 `110000` |
| `districtCode` | `sgguCd` | HIRA 6자리 시군구코드. 강남구 `110001`, 서초구 `110021`, 중랑구 `110019` |
| `town` | `emdongNm` | 읍면동명 |
| `institutionTypeCode` | `clCd` | 2자리 종별코드. 종합병원 `11`, 의원 `31` |
| `departmentCode` | `dgsbjtCd` | 2자리 진료과목코드. 내과 `01`, 소아청소년과 `11` |
| `page`·`limit` | `pageNo`·`numOfRows` | 기본 1·10, KoreAI 제한 1~1000쪽·1~100개 |

병원명·시도·시군구 중 한 가지 이상이 필요합니다. 지역·종별·진료과목은 **HIRA 코드**이며 정보나루·다른 공공 API 코드와 다릅니다. [공식 코드 조회](https://opendata.hira.or.kr/op/opc/selectColumnCodeList.do)의 지역코드·종별코드·진료과목코드에서 확인합니다. 코드 형식과 시도/시군구 접두 지역은 엔진에서 검사하며 전체 코드의 유효성은 공급자 명세로 확인해야 합니다. 코드 이름 검색 기능은 후속 작업입니다.

첫 번째 예시는 공식 Swagger의 형식 예시이며 현재 검색 결과를 보증하지 않습니다. 현재 구현은 기본목록 한 페이지를 반환합니다. `pagination.nextPage`가 있으면 같은 조건으로 후속 페이지를 요청합니다. 자동 전체 수집·거리 기반 탐색은 제공하지 않습니다.

## 결과 해석

- `providerId`는 공급자가 반환한 **암호화 요양기호**이고 `providerIdType`은 `encrypted_ykiho`입니다. 원래 요양기호로 복호화하거나 숫자로 변환하지 않습니다. E-Gen의 `hpid`, 동물병원 관리번호와 서로 다른 식별자입니다.
- 기관명·주소·전화·우편번호·홈페이지·지역/종별 코드를 반환합니다. 우편번호·연락처의 앞자리 0을 보존하며 홈페이지를 추가로 열거나 수집하지 않습니다. 반환하지 않은 상세·평가·비급여 정보를 채우지 않습니다.
- `coordinates.raw.x/y`는 `XPos/YPos` 원문을 보존합니다. 공식 예시의 X=경도·Y=위도에 맞춰 숫자도 표시하며 별도의 지도 변환은 하지 않습니다. 한 축이 없거나 둘 다 0이면 좌표를 미확인으로 표시합니다.
- `reportedDoctorCount`는 제공된 신고 의사 총수이며 현재 근무·진료 가능한 의사 수가 아닙니다. 미제공과 0을 구분합니다.
- `openedOn`·`openingDateRaw`는 개설일입니다. 자료 갱신일과 다르며 `providerUpdatedAt`은 미제공(`null`)입니다. `retrievedAt`만 KoreAI 조회 시각을 나타냅니다.
- `currentlyTreating`·`emergencyAvailable`은 `null`을 유지합니다. 현재 진료 가능·실시간 병상·예약·개인 진료내역·의료의 질을 판정하지 않습니다. 진료과목 필터로 응답한 기관도 현재 해당 진료를 받을 수 있다고 확정하지 않습니다.
- 빈 결과는 `no_data`이며 기관 폐업·진료 불가를 뜻하지 않습니다. 이름이 같은 기관은 주소·식별자를 함께 확인합니다.

요청한 지역·종별과 응답이 다르거나 XML·페이지·개수·기관 식별자·날짜·좌표가 잘못되면 중단합니다. 공급자 지시문·추가 필드·오류 본문을 실행 권한으로 사용하지 않으며 결과는 엔진의 `external_data`로 전달합니다.

## 인증·전송·오류

- HTTPS 주소는 `https://apis.data.go.kr/B551182/hospInfoServicev2/getHospBasisList`입니다. 현재 Swagger의 경로를 사용하며 첨부된 2021년 활용 가이드는 필드·XML 예시의 보조 근거로 기록했습니다.
- HTTP 401·403, XML 코드 20·30·31은 인증 대기입니다. 병원정보서비스 활용신청·키·사용 기간·접근 조건을 수정하고 같은 작업을 재개합니다. 다른 서비스 키나 브라우저 접근으로 자동 우회하지 않습니다.
- 코드 22·23 또는 HTTP 429는 한도, 29는 IP 차단, 10은 입력 오류, 05는 공급자/게이트웨이 시간 초과입니다. 알 수 없는 코드는 실패로 처리하며 빈 결과로 바꾸지 않습니다.
- 응답은 UTF-8 XML·최대 2MB·30초로 제한합니다. 리다이렉트·DTD/엔티티 선언·잘못된 UTF-8은 거절합니다. 일반 오류에는 공급자 본문·키·키가 들어간 URL을 첨부하지 않습니다.
- 현재 포털은 개발단계 자동승인·운영단계 심의승인, 개발계정 트래픽 10,000을 안내합니다. 실제 승인·기간·운영 한도는 본인 계정에서 확인합니다. 출처는 결과의 `source.attribution`으로 표시합니다.
