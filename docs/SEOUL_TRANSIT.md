# 서울·수도권 지하철과 또타라커

확인일: **2026-10-22**. 도착정보·예정 시간표 API 두 조회와 공식 노선도/또타라커 앱의 기본 연결을 추가했습니다. **본인 키의 정상 응답 검증은 대기**입니다. 또타라커 실시간 빈칸은 승인된 제공 경로를 확인해야 합니다.

## 시작하기

1. 서울 열린데이터광장에서 본인 인증키와 각각의 지하철 API 이용 조건·권한을 확인합니다. 기존 따릉이 계정이나 `sample` 키를 자동 사용하지 않습니다.
2. 서버 운영자가 공급자까지의 HTTP 키 전송을 확인하고 **서버 실행 환경에** `KOREAI_ALLOW_SEOUL_SUBWAY_HTTP=1`을 지정한 뒤 재시작합니다. 기본은 차단이며 브라우저·에이전트 입력으로 변경할 수 없습니다. 따릉이 허용 설정과 독립적입니다.
3. **연결 계정 → 서울 지하철 도착·시간표**에서 `apiKey`와 필요한 행동만 허용합니다. 서비스별 키가 다르면 계정을 따로 등록합니다.
4. **확장 계획 → 서울·수도권 지하철**에서 도착 또는 시간표를 선택합니다. 역 이름·조건·계정을 확인하고 키 없는 요청 미리보기 후 실행합니다. 외부 에이전트와 DeepSeek 대화에도 행동·계정을 별도로 허용해야 합니다.

HTTP 구간에서는 키와 응답이 암호화되지 않고 출처 무결성을 확인하지 못합니다. HTTPS 프로브는 이번 환경에서 연결 시간 초과였습니다. HTTP로 자동 폴백하지 않으며 공식 HTTP 경로는 위 운영자 설정 후에만 사용합니다. 키는 서버 실행 시 경로에 한 번 인코딩하고 미리보기·응답·일반 로그에 제공하지 않습니다. 역·필터는 해당 공급자로 전송됩니다. 운영 프록시에서도 키가 포함된 요청 경로를 기록하지 않아야 합니다.

## 지도

**기본 서비스 연결 → 서울·수도권 지하철** 또는 지하철 조건 화면에서 [서울교통공사 공식 사이버스테이션](https://www.seoulmetro.co.kr/kr/cyberStation.do)과 [공식 노선도 원본 파일 안내](https://www.data.go.kr/data/15120713/fileData.do)를 엽니다. 공공데이터포털은 해당 사이버스테이션 주소와 국·영·중·일 원본 자료를 안내합니다. 자료는 기준 시점과 개통·운행 변경을 확인하세요.

노선도는 공식 화면/원본으로 직접 확인하는 단계입니다. KoreAI 자체 노선도 렌더링·최단 경로·환승 계산은 후속 범위이며 링크 열기를 API 조회 실적으로 집계하지 않습니다. 원본 노선도 자료의 공공누리 제3유형(출처표시·변경금지)을 확인했으며 이번에는 이미지를 복제/변형하지 않았습니다. 사이버스테이션의 이번 서버 측 접속은 시간 초과여서 실제 페이지 조작은 검증하지 않았습니다.

## 실시간 도착

[공식 도착정보 명세](https://data.seoul.go.kr/dataList/OA-12764/A/1/datasetView.do)의 `seoul-subway.arrivals`를 사용합니다.

```json
{"stationName":"서울","limit":5}
```

고정 `http://swopenapi.seoul.go.kr/api/subway/{apiKey}/json/realtimeStationArrival/0/{limit}/{stationName}` 경로입니다. 이름은 공식 표기이며 ‘서울역’을 ‘서울’로 임의 변환하지 않습니다. `limit`는 1~100, 기본 20입니다. 서울시 외 일부 구간은 미제공이며 역별 별칭은 공급자 안내를 확인하세요.

반환한 `rows`는 호선·열차 번호·방향·행선지·도착 메시지·`reportedArrivalSeconds`·`providerCreatedAtRaw`·`ageSeconds`·막차 보고를 제공합니다. 공급자 예보 `0`을 현재 도착으로 단정하지 않고 `adjustedArrivalSeconds`는 `null`입니다. 생성 후 60초 초과·미래 시각은 화면에서 경고합니다. 빈 목록으로 운행 종료·첫차·막차 종료를 추정하지 않습니다. 60초 뒤 작업 결과는 공통 엔진에서 만료되어 모델에 재전송하지 않습니다. 자동 갱신은 하지 않습니다.

## 예정 시간표

[현행 시간표 명세](https://data.seoul.go.kr/dataList/OA-22750/A/1/datasetView.do)의 `seoul-subway.timetable`를 사용합니다. 과거 `SearchSTNTimeTableByIDService`를 새 명세로 오인하지 않습니다.

```json
{"stationName":"서울","lineName":"1호선","direction":"상행","day":"평일","temporary":"N","at":"2026-10-22T09:00:00+09:00","limit":5}
```

고정 `http://openapi.seoul.go.kr:8088/{apiKey}/json/getTrainSch/1/{limit}/%20/{temporary}/{direction}/{day}/{lineName}`과 쿼리 `stnNm/searchDt`를 사용합니다. 역·호선은 **포함 검색**, 방향은 상행/하행/내선/외선, 요일은 평일/주말/상시, 임시는 N/Y입니다. 공휴일·현재 요일을 자동 판정하지 않습니다. `at` 생략 시 실행 시각을 한국 시간으로 변환해 전송하며 요청 미리보기 시각과 실제 실행 시각은 달라질 수 있습니다.

실제 공개 샘플은 명세 공통 설명과 달리 `response.header.resultCode`·`response.body.items.item/pageNo/numOfRows/totalCount` 구조를 반환했습니다. 이를 검증하고 첫 구간만 제공합니다. 전체/수신 수와 잘린 구간을 표시하며 자동 페이지 순회·다음 열차 계산은 하지 않습니다. 공급자 결과는 시간순을 보장하지 않습니다.

예정 출발·도착·유효 시작/종료를 원문으로 보존합니다. 24시 이후 표기는 운행일 기준 시간이며 달력 날짜로 임의 환산하지 않습니다. 기준 시각이 양쪽 유효기간 안인지 `validAtQuery`로 표시하고 기간 미제공은 `null`, 기간 밖은 `false`입니다. **공개 샘플에 2025년 유효기간 자료가 있었으므로 현재 시간표로 판정하지 않습니다.** 실제 운행과 지연·승차 가능도 별도입니다.

## 또타라커·사물함

**기본 서비스 연결 → 또타라커**에서 [운영사 안내](https://www.smrte.co.kr/support/happybox), Android/iPhone 공식 앱, [설치 수량 공공자료](https://www.data.go.kr/data/15044235/fileData.do)를 선택해 준비 상태를 저장합니다. 사용자가 앱에서 역·크기·현재 빈칸을 직접 확인합니다. 설치 수량은 분기 자료이며 실시간 빈칸이 아닙니다.

`tlocker.availability`는 **비활성 제안 규격**입니다. `stationName/size`를 입력하고 공급자 ID·위치·크기·설치/빈칸 수·관측 시각·고장/미확인 상태를 분리합니다. 없는 빈칸 수는 `null`이며 `0`과 구분합니다. 빈칸 수를 제공하려면 관측 시각·고유 ID·상태·설치 수량과의 관계가 유효해야 합니다. 운영사의 공개 소비자 API를 확인하지 못해 아직 네트워크 호출·키 등록·지원 집계는 하지 않습니다. 자동화는 승인된 조회 경로 확보 후 활성화하며 예약·결제·문 열기는 별도 행동입니다. 앱의 내부 엔드포인트를 추측해 호출하지 않습니다.

## 결과와 후속 검증

두 API는 읽기 행동이며 30초·2MB·UTF-8·JSON/XML 오류 검사, 리다이렉트/자동 재시도 금지, 요청 필터·수신 건수·중복 검사와 공통 계정/클라이언트 권한을 적용합니다. 실제 도착 API 무효 키 응답은 정상 조회의 errorMessage 래퍼 없이 최상위 status/code를 반환했습니다. 이 차이도 처리합니다. 공급자 인증 오류는 인증 대기로 보존해 같은 작업에서 재개하며 오류 본문은 모델에 노출하지 않습니다. 무효 키·빈 응답·서비스 오류를 정상 데이터로 바꾸지 않습니다.

현재 제공 범위는 API 2행동, 기본 진입 안내 2서비스·4행동, 비활성 빈칸 제안 1개입니다. 실제 본인 키·정상/빈 목록·역 별칭·현재 유효 시간표·한도/이용 조건·Linux 브라우저·실물 휴대폰은 별도 검증합니다. [검증 기록](VALIDATION.md#2026-10-22-지하철또타라커-연결-검증), [다음 할 일](../TODO.md#바로-이어서-개발할-순서)
