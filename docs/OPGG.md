# OP.GG 공개 게임 조회

확인일: **2026-10-20**. OP.GG가 배포한 [공식 공개 MCP](https://github.com/opgginc/opgg-mcp/blob/main/README.ko.md)를 이용합니다. 접속 주소는 `https://mcp-api.op.gg/mcp`이며 현재 **API 키·OP.GG 로그인·Riot 계정 연결 없이** 아래 다섯 조회를 실행할 수 있습니다. 게임 클라이언트 설치도 필요 없습니다.

## 사용 순서

1. KoreAI를 실행하고 관리 화면의 **확장 계획**에서 `OP.GG`를 검색합니다.
2. 사용할 조회 기능을 선택하고 **예시 입력 불러오기**를 누릅니다.
3. 입력을 수정합니다. **요청 구조 미리보기**는 외부로 전송하지 않습니다.
4. **실행 요청**을 누르고 **작업과 승인**에서 결과를 확인합니다. 공개 읽기 행동이므로 별도 계정 등록이나 쓰기 승인은 요구하지 않습니다.

DeepSeek로 요청하려면 **AI 대화 → 새 대화 → 대화에 허용할 기능**에서 원하는 OP.GG 행동을 선택하세요. 기존 대화의 허용 범위는 자동으로 늘어나지 않습니다. 모델 호출에는 기존 DeepSeek 키가 필요하지만 OP.GG 조회용 키는 필요 없습니다. 이번 실제 서비스 검증은 HTTP API로 수행했으며 DeepSeek의 자연어 선택·응답까지 새로 시험한 결과는 아닙니다.

## 제공 행동

| 행동 ID | 입력 예시 | 반환 범위 |
|---|---|---|
| `opgg.lol.profile` | `{"gameName":"Hide on bush","tagLine":"KR1","region":"KR"}` | 공개 프로필·레벨·랭크 큐별 티어/LP·승패·제공된 갱신 시각 |
| `opgg.lol.matches` | `{"gameName":"Hide on bush","tagLine":"KR1","region":"KR","limit":5}` | 최근 경기 5~20개에서 요청한 플레이어의 챔피언·포지션·킬/데스/어시스트·결과 |
| `opgg.lol.meta` | `{"position":"mid","limit":10}` | 라인별 챔피언·공급자 순위/티어·승률/픽률/밴률, 최대 30개 |
| `opgg.tft.meta` | `{"limit":5}` | 공급자 목록 앞부분의 메타 덱·한국어 이름·조합 코드·유닛/아이템 키·제공 통계, 최대 10개 |
| `opgg.valorant.agents` | `{"name":"제트","limit":10}` | 한국어/영문 이름으로 받은 목록을 필터링한 요원·스킬명, 최대 30개 |

LoL 플레이어 조회는 현재 **한국 서버 `KR`**만 받습니다. Riot ID의 이름과 `#` 뒤 태그라인을 따로 넣습니다. 이름에 `#`·제어문자, 태그라인에 `#`·공백·제어문자를 넣을 수 없습니다. `region` 생략 시 `KR`, 최근 경기 `limit` 생략 시 5입니다. 라인은 `top`, `jungle`, `mid`, `adc`, `support` 중 하나입니다. 발로란트 `name`은 생략할 수 있습니다.

Riot ID는 **실행 시 OP.GG 공식 서버로 전송**되고 로컬 작업·대화 이력에도 남습니다. 공개 전적 조회는 계정 소유를 인증하지 않으며, 프로필 결과의 `accountOwnershipVerified`는 `false`입니다. 사용자 계정 토큰·쿠키는 전송하지 않습니다. HTTP/MCP 클라이언트에는 필요한 행동만 허용하면 되며 OP.GG용 계정 범위는 필요 없습니다.

## 결과 해석

- 모든 결과에 OP.GG 출처·공식 MCP 주소·조회 시각을 붙입니다. 공급자의 갱신 시각은 별도 원문 값으로 보존합니다. 이번 조회가 전적 갱신을 요청했다는 뜻은 아닙니다.
- 프로필의 미배치 티어·누락 LP·누락 지역은 `null`로 보존합니다. 응답에 Riot ID가 있으면 요청 대상과 대조하며 다른 플레이어의 프로필을 성공으로 반환하지 않습니다.
- 최근 전적은 요청한 플레이어만 반환합니다. 경기 ID 중복·대상 누락/중복은 오류로 중단하고, 데스 0을 그대로 보존합니다. 무한 KDA나 실시간 경기 상태를 만들지 않습니다.
- 챔피언·TFT 통계의 비율은 **0~1**입니다. LoL 통계의 지역·표본 티어·패치는 현재 선택한 응답에 없어 `null`입니다. TFT는 공급자 목록 앞부분이며 개인 추천 순위로 재정렬하지 않습니다.
- 발로란트 행동은 요원·스킬 사전입니다. 개인 전적·현재 메타 순위를 제공하지 않으며 `currentMetaRank`는 `null`입니다.
- 응답은 `external_data`로 전달합니다. 페이지나 도구 결과의 문구는 행동 권한·승인 조건을 바꾸지 못합니다.

## 구현과 호환성

공식 서버의 실제 도구 발견은 2026-10-20 기준 29개였습니다. 이 중 **검토한 다섯 조회만** `opgg-public-mcp` 커넥터에 내장합니다. 원격 목록에 추가된 행동을 자동 공개하지 않으며 임의 도구명·주소·출력 필드를 입력받지 않습니다.

현재 서버의 일부 도구는 `outputSchema.type: array`를 선언해 일반 MCP SDK의 도구 목록 검증과 맞지 않습니다. 전용 어댑터에서 목록의 이름·객체 입력 규격만 검증하고, 선택한 도구의 최신 입력 규격을 다시 검사한 뒤 호출합니다. 선택한 도구가 없어지거나 규격이 맞지 않으면 실제 조회 전에 중단합니다. 다른 상위 MCP 서버의 SDK 검증과 **사용자 설치 MCP의 쓰기 승인 정책은 그대로 적용**합니다.

LoL 세 행동은 실제로 JSON 대신 `class Name: field` 선언과 생성자 표기를 반환했습니다. 별도 파서는 문자열·숫자·배열·정해진 필드의 객체만 데이터로 읽습니다. `eval`·함수 실행·속성 접근을 사용하지 않으며 알 수 없는 생성자·중복/특수 필드·초과 깊이·뒤따른 명령을 거절합니다. TFT·발로란트는 JSON을 검증합니다. 필요한 필드만 결과에 남기고 공급자의 원문 응답을 그대로 전달하지 않습니다.

접속은 고정 HTTPS 주소로 제한하고 리다이렉트를 거절합니다. 전체 시간 제한은 30초, 응답당 최대 2MB·데이터 문자열 최대 100만 자입니다. UTF-8 오류·응답 구조 변경은 실패로 처리하고 자동 재시도하지 않습니다. 429는 호출 한도 오류, 401/403은 공급자 접근 조건 확인을 위한 대기 상태로 남깁니다. 현재 공개 연결에 임의 키를 추가하거나 브라우저로 우회하지 않습니다.

## 검증과 남은 작업

2026-10-20에 **KoreAI HTTP 작업 생성 → 실제 OP.GG MCP → 정규화 결과 조회**를 다섯 행동 모두 성공했습니다. 공개 LoL 예시의 프로필·최근 5경기, 미드 챔피언 10개, TFT 덱 5개, 제트 요원 1개를 확인했습니다. 인증 정보와 사용자 DB를 사용하지 않고 별도 무시된 시험 폴더에서 실행했습니다.

모의 검증은 전용 12개 테스트와 390×844 모바일 크기 UI 흐름 1개를 포함합니다. Windows 전체 307개 통과·Linux 전용 2개 제외, WSL2 Ubuntu 24.04·Node 22.17의 OP.GG/MCP OAuth·기존 확장 관련 32개가 통과했습니다. Linux 브라우저·실제 휴대폰·GCP 배포·실제 공급자 429/규격 변경까지 검증한 결과는 아닙니다. 상세 범위는 [검증 기록](VALIDATION.md#2026-10-20-opgg-공개-mcp-조회-검증)을 참고하세요.

시험 DB의 실제 성공 증거는 사용자 DB에 가져오지 않으며 배포 지원으로 자동 지정하지 않습니다. 네이버 중단을 반영한 공식 API 25개 커넥터·44개 행동과 별도로 **공식 공개 MCP 1개·조회 5개**로 집계합니다.
